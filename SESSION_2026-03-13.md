## Архитектура системы

### 3 воркфлоу в n8n + Google Sheets + Python парсер

```
Workflow 1 (Bot)  →  Google Sheets  ←  Workflow 2 (Parser)
                                              ↓
                                    Workflow 3 (Warming)
```

---

## Workflow 1 — 🤖 AI Agent — Bot Control
**Триггер:** Telegram сообщения (всегда активен)

**Команды:**
| Команда | Действие |
|---|---|
| `/add_niche аренда квартир Москва СВАО` | Claude → профиль ниши → /search_channels → Claude скоринг → sources (pending) → карточки с ✅/❌ |
| `/approve_sources` | Показывает pending каналы с кнопками одобрения |
| `/start_parse` | POST на PARSER_WORKFLOW_WEBHOOK → запускает Workflow 2 |
| `/leads` | Горячие лиды (priority=A) из таблицы |
| `/niches` | Активные ниши |
| `/status` | Счётчик: одобрено / ожидают / отклонено |

**Callback кнопки:**
- `approve_@username` → sources.approved = yes
- `reject_@username` → sources.approved = rejected
- `send_<post_url>` → leads.status = message_sent

---

## Workflow 2 — ⚙️ AI Parser + Lead Processor
**Триггер:** Расписание каждые 6ч + webhook от бота (`/ai-parse-trigger`)

**Поток:**
1. Читает `sources` (approved=yes)
2. Читает `niches` (lead_signals как ключи)
3. POST `http://172.17.0.1:5000/parse` → посты
4. Claude Haiku анализирует каждый пост → priority/summary/first_message
5. appendOrUpdate в `Telegram_Leads_Template` (match by post_url)
6. Если priority=A → уведомление в Telegram

---

## Workflow 3 — 💬 Smart Lead Warming
**Триггер:** Расписание каждые 2ч

**Поток:**
- **Ветка 1:** status=new + ai_priority=A + есть username → Claude пишет первое сообщение → POST `http://172.17.0.1:5000/send_message` → status=contacted
- **Ветка 2:** status=contacted + 24ч без ответа + follow_up_count<2 → Claude пишет follow-up → follow_up_count++

**Статусы лида:**
```
new → contacted → follow_up_1 → follow_up_2
              ↘ contact_failed
              ↘ message_sent (ручная отправка через бота)
```
