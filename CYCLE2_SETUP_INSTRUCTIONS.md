# Цикл 2 - Автоматический поиск сайтов компаний

## 📋 Описание

**Цикл 2** - это автоматический workflow, который:
1. ✅ Читает запросы из таблицы (лист "Запросы", где Статус=0)
2. ✅ Для каждого запроса использует Perplexity AI для поиска сайтов компаний
3. ✅ Извлекает информацию о компаниях (название, сайт, город)
4. ✅ Сохраняет найденные компании в лист "Компании"
5. ✅ Обновляет статус запроса на "1" (выполнено)
6. ✅ Запускается автоматически каждые 10 минут

---

## 🚀 Установка

### Шаг 1: Импортировать workflow в n8n

1. Откройте n8n
2. Нажмите **"Import from File"**
3. Выберите файл: `cycle2_find_company_websites.json`
4. Workflow будет импортирован с названием **"Цикл 2 - Поиск сайтов компаний"**

### Шаг 2: Настроить Perplexity API Key

**ВАЖНО!** Замените `YOUR_PERPLEXITY_API_KEY_HERE` на ваш реальный API ключ:

1. Откройте узел **"Perplexity - Поиск сайтов"**
2. Найдите Headers → Authorization
3. Замените значение на: `Bearer ВАШ_API_КЛЮЧ`
4. Сохраните

**Где взять API ключ:**
- Зарегистрируйтесь на https://www.perplexity.ai/
- Перейдите в Settings → API
- Создайте новый API ключ
- Скопируйте ключ

### Шаг 3: Проверить настройки Google Sheets

Убедитесь, что в вашей таблице есть:

#### Лист "Запросы" (gid=1305865408):
| Столбец | Описание |
|---------|----------|
| Запросы | Текст запроса (например: "хабаровск+агентство+недвижимости+улица_ленина") |
| Статус выполнения | `0` = не выполнено, `1` = выполнено |

| Столбец | Описание |
|---------|----------|
| Название компании | Название найденной компании |
| Сайт | URL сайта компании |
| Город | Город компании |
| Запрос | Исходный поисковый запрос |
| Дата добавления | ISO дата добавления |
| Статус | Статус обработки (new, processed, etc.) |

**Если листов нет - создайте их с этими столбцами!**

## ⚙️ Настройки

### Изменить частоту запуска:

1. Откройте узел **"Каждые 10 минут"**
2. Измените интервал (например: каждые 5 минут, каждый час, и т.д.)
3. Сохраните

### Изменить количество обрабатываемых запросов за раз:

1. Откройте узел **"Цикл по запросам"**
2. Options → Batch Size (по умолчанию: 1)
3. Увеличьте, чтобы обрабатывать несколько запросов параллельно
4. **Внимание:** Perplexity имеет лимиты запросов в минуту!

### Изменить промпт для поиска:

1. Откройте узел **"Perplexity - Поиск сайтов"**
2. Измените поле **jsonBody** → `messages[0].content` (system prompt)
3. Можете настроить формат ответа, критерии поиска и т.д.

## 🐛 Устранение ошибок

### Ошибка: "Authorization failed"
**Решение:** Проверьте API ключ Perplexity в узле "Perplexity - Поиск сайтов"

### Ошибка: "Sheet not found"
**Решение:** Создайте листы "Запросы" и "Компании" в таблице с правильными столбцами

### Компании не сохраняются
**Решение:**
1. Проверьте логи выполнения workflow (Executions)
2. Убедитесь, что Perplexity возвращает JSON в правильном формате
3. Проверьте узел "Извлечь компании" - там есть парсинг ответа

### Статус запроса не обновляется
**Решение:**
1. Убедитесь, что столбец "Запросы" используется для сопоставления
2. Проверьте, что значение в столбце точно совпадает с исходным запросом

## 📈 Мониторинг

### Как проверить работу:

1. Откройте workflow "Цикл 2"
2. Перейдите в раздел **"Executions"**
3. Смотрите историю выполнений
4. Для каждого выполнения видны:
   - Сколько запросов обработано
   - Сколько компаний найдено
   - Какие ошибки возникли

### Метрики:

- **Success Rate**: сколько запросов успешно обработано
- **Companies Found**: среднее количество компаний на запрос
- **Execution Time**: время выполнения одного цикла

## 💡 Рекомендации
