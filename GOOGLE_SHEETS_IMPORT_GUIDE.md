## 🚀 Способ 1: Импорт в существующую таблицу (Рекомендуется)

### Шаг 1: Откройте вашу таблицу

```
https://docs.google.com/spreadsheets/d/1dqpNAXH8HmK_kExVa2wMeHAeF35x8-MIXN0xQbNUk8Y/
```

---

### Шаг 2: Импортировать лист "Запросы"

1. В правом нижнем углу нажмите **"+" → "Импортировать лист"**

   Или: **Файл → Импорт**

2. Выберите вкладку **"Загрузка"**

3. Нажмите **"Выбрать файл на устройстве"**

4. Выберите файл: **`sheet_zapros.csv`**

5. В настройках импорта выберите:
   - **Место импорта:** "Вставить новые листы" или "Заменить текущий лист"
   - **Разделитель:** Запятая

6. Нажмите **"Импортировать данные"**

7. **Переименуйте лист:** кликните на название листа внизу → "Переименовать" → **"Запросы"**

---

### Шаг 3: Импортировать лист "Компании"

1. Повторите то же самое для файла **`sheet_companies.csv`**

2. Переименуйте лист в **"Компании"**

## 🎯 Способ 2: Создать новую таблицу (Альтернатива)

3. Импортируйте оба файла как описано выше

4. **Скопируйте URL** новой таблицы

5. **Замените ID таблицы** во всех workflows:
   - Старый ID: `1dqpNAXH8HmK_kExVa2wMeHAeF35x8-MIXN0xQbNUk8Y`
   - Новый ID: (из URL новой таблицы)

## 🔧 После импорта: Настроить n8n

### В главном workflow ("АГЕНТ ЛИДЫ+КП 2026_v2.0"):

#### 1. Узел для добавления запросов (Google Sheets):
- **Document:** Ваша таблица
- **Sheet:** Выберите **"Запросы"** из списка
- Columns: Запросы, Статус выполнения

#### 2. Узел "QuerySheets":
- **Document:** Ваша таблица
- **Sheet:** **"Запросы"**
- Filters: Статус выполнения = 0

#### 3. Узел "SiteCompanySheets":
- **Document:** Ваша таблица
- **Sheet:** **"Компании"**
- Filters: Статус получения данных = 0

---

### В Цикле 2 ("Цикл 2 - Поиск сайтов компаний"):

#### 1. Узел "Прочитать запросы":
- **Document:** Ваша таблица
- **Sheet:** **"Запросы"**
- Filters: Статус выполнения = 0

#### 2. Узел "Сохранить компании":
- **Document:** Ваша таблица
- **Sheet:** **"Компании"**
- Columns: Название компании, Сайт, Город, Запрос, Дата добавления, Статус

#### 3. Узел "Обновить статус запроса":
- **Document:** Ваша таблица
- **Sheet:** **"Запросы"**
- Update: Статус выполнения = 1

## 📋 Структура листов

### Лист "Запросы":

| Столбец | Тип | Описание |
|---------|-----|----------|
| Запросы | Текст | Поисковый запрос в формате: "город+тематика+улица" |
| Статус выполнения | Число | 0 = не обработан, 1 = обработан |

**Примеры запросов:**
- `хабаровск+агентство+недвижимости+улица_ленина`
- `хабаровск+агентство+недвижимости+проспект_60летия`
- `москва+стоматология+улица_арбат`

---

### Лист "Компании":

| Столбец | Тип | Описание |
|---------|-----|----------|
| Название компании | Текст | Название найденной компании |
| Сайт | Текст | URL сайта (https://example.com) |
| Город | Текст | Город компании |
| Запрос | Текст | Исходный поисковый запрос |
| Дата добавления | Дата/Текст | ISO формат: 2026-01-12T10:30:00Z |
| Статус получения данных | Число | 0 = новая, 1 = данные собраны |

## 🆘 Возможные проблемы

### Проблема: "Sheet not found"

**Решение:**
- Убедитесь что листы названы ТОЧНО: "Запросы" и "Компании" (с заглавной буквы)
- В n8n кликните на выбор листа и обновите список (кнопка refresh)

---

### Проблема: Данные не сохраняются

**Решение:**
- Проверьте права доступа: Google Sheets API должен иметь доступ к таблице
- В n8n проверьте Credentials для Google Sheets

---

### Проблема: Цикл 2 не находит компании

**Решение:**
- Проверьте Perplexity API ключ
- Посмотрите Executions Цикла 2 - там должны быть подробности ошибки
