## 🔧 Технологии

- **Telegram Bot API** - интерфейс
- **Wildberries API** - получение данных (бесплатно!)
- **n8n** - автоматизация workflow
- **Google Sheets** - хранение данных
- **OpenRouter AI** - анализ стратегий

---

## 📊 Архитектура

```
Telegram Bot
    ↓
n8n Workflow:
1. Parse Command (добавить/удалить/список артикулов)
2. Fetch WB API (получить данные по артикулу)
3. Save to Google Sheets (сохранить цену)
4. Compare Prices (сравнить с предыдущей ценой)
5. AI Analyze (анализ если цена изменилась)
6. Send Alert (уведомление пользователю)

Cron Job (каждый час):
- Проверить все артикулы из Sheets
- Сравнить с предыдущими ценами
- Отправить уведомления
```

## 🔑 WB API

**Endpoints:**

1. **Поиск товара по артикулу:**
```
https://card.wb.ru/cards/detail?nm={артикул}
```

2. **Получить цену:**
```
https://basket-{N}.wb.ru/vol{VOL}/part{PART}/{артикул}/info/price-history.json
```

3. **Карточка товара:**
```
https://www.wildberries.ru/catalog/{артикул}/detail.aspx
```

**Лимиты:** Нет официальных лимитов для публичного API
