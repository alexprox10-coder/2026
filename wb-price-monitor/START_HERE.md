## ✅ ВАРИАНТ 1: БЫСТРЫЙ ТЕСТ (рекомендую начать с него!)

**Файл:** `workflows/SIMPLE_TEST_BOT.json`

**Что делает:**
- Вы отправляете артикул WB → бот показывает цену и информацию
- БЕЗ базы данных
- БЕЗ AI
- БЕЗ сохранения

**Зачем:** Проверить что WB API работает и бот отвечает

**Время настройки:** 5 минут

### Шаги:

1. **Создайте Telegram бота:**
   - Найдите @BotFather в Telegram
   - `/newbot`
   - Сохраните токен

2. **Импортируйте в n8n:**
   - Workflows → Import from File
   - Выберите: `SIMPLE_TEST_BOT.json`
   - Укажите Telegram credential
   - Активируйте (Active = ON)

3. **Тестируйте:**
   - Откройте бота в Telegram
   - Отправьте: `/start`
   - Отправьте любой артикул WB, например: `123456789`
   - Должна прийти информация о товаре!

✅ **Работает? Переходите к Варианту 2!**

---

## ✅ ВАРИАНТ 2: ПОЛНАЯ ВЕРСИЯ (с AI и базой данных)

**Файл:** `workflows/FULL_WITH_AI_AND_SHEETS.json`

**Что делает:**
- Команда `/add 123456789` → добавляет товар на мониторинг
- AI анализирует товар и дает рекомендации
- Сохраняет всё в Google Sheets
- В будущем - автопроверка цен каждый час

**Зачем:** Полноценный мониторинг с AI

**Время настройки:** 30 минут

### Шаги:

1. **Настройте Google Sheets:**
   - Создайте таблицу
   - Добавьте лист "Products" с заголовками
   - Настройте OAuth2

   📖 **Подробная инструкция:** `docs/GOOGLE_SHEETS_SETUP.md`

2. **Получите OpenRouter API ключ:**
   - Зарегистрируйтесь: https://openrouter.ai/
   - Пополните баланс ($5)
   - Скопируйте API key

3. **Импортируйте в n8n:**
   - Workflows → Import from File
   - Выберите: `FULL_WITH_AI_AND_SHEETS.json`
   - Настройте 3 credentials:
     - Telegram Bot API
     - Google Sheets OAuth2
     - OpenRouter API (в HTTP Request ноде)
   - В Google Sheets ноде укажите ID вашей таблицы
   - Активируйте

4. **Тестируйте:**
   - Откройте бота
   - `/start`
   - `/add 123456789`
   - Должно прийти: информация о товаре + AI анализ + "Сохранено в Google Sheets"
   - Проверьте Google Sheets - должна появиться строка!

## ❓ Проблемы?

**Бот не отвечает:**
- Проверьте что workflow Active
- Проверьте токен бота

**Товар не найден:**
- Проверьте артикул (только цифры)
- Попробуйте другой артикул

**AI не работает:**
- Проверьте OpenRouter API ключ
- Проверьте баланс на OpenRouter

**Google Sheets не сохраняет:**
- Проверьте ID таблицы
- Проверьте названия столбцов
- Проверьте OAuth2 credential
