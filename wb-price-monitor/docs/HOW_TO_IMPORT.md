# 🔧 Как импортировать workflow в n8n

---

## 📥 Вариант 1: ПРОСТОЙ (рекомендую для старта)

**Импортируйте только ОДИН файл:** `WB_COMPLETE_BOT.json`

Этот файл содержит ВСЁ:
- Все команды бота (/start, /add, /list, /price, /remove)
- WB API парсинг
- Google Sheets сохранение
- AI анализ (опционально)

### Шаги:

1. **Откройте n8n:** https://n8n.arendadom24.ru
2. **Workflows** → **Import from File**
3. Выберите: `workflows/WB_COMPLETE_BOT.json`
4. Нажмите **Import**
5. **Откройте импортированный workflow**
6. **Настройте credentials:**
   - Telegram Bot API
   - Google Sheets OAuth2
   - OpenRouter API (для AI)
7. **Сохраните**
8. **Активируйте** (переключатель Active)

✅ **Готово!** Один workflow - всё работает!

---

## 📥 Вариант 2: РАСШИРЕННЫЙ (если хотите отдельные workflow)

Если хотите разделить функциональность:

### Workflow 1: **WB_PRICE_MONITOR_MAIN.json**
**Назначение:** Основной бот с командами

**Импорт:**
1. Workflows → Import from File
2. Выберите: `WB_PRICE_MONITOR_MAIN.json`
3. Название: "WB Price Monitor - Main Bot"
4. Настройте credentials
5. Активируйте

### Workflow 2: **WB_AI_ANALYSIS.json**
**Назначение:** AI анализ изменений цен

**Импорт:**
1. Workflows → Import from File
2. Выберите: `WB_AI_ANALYSIS.json`
3. Название: "WB Price Monitor - AI Analysis"
4. Настройте OpenRouter API key
5. **НЕ АКТИВИРУЙТЕ** (он вызывается из другого workflow)

### Workflow 3: **WB_CRON_CHECK_PRICES.json** (создам отдельно)
**Назначение:** Автоматическая проверка цен каждый час

## 🔄 Как работают несколько workflow вместе:

```
┌─────────────────────────────────────┐
│ WB_PRICE_MONITOR_MAIN.json          │
│ (Active - слушает Telegram)         │
│                                     │
│ 1. /add → Сохранить в Google Sheets │
│ 2. /list → Показать список          │
│ 3. /price → Проверить цену          │
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│ WB_CRON_CHECK_PRICES.json           │
│ (Active - запуск каждый час)        │
│                                     │
│ 1. Читает товары из Google Sheets   │
│ 2. Проверяет цены через WB API      │
│ 3. Сравнивает с предыдущей ценой    │
│ 4. Если изменилась → вызывает AI    │
└──────────────┬──────────────────────┘
               │
               ▼ (если цена изменилась)
┌─────────────────────────────────────┐
│ WB_AI_ANALYSIS.json                 │
│ (Вызывается другими workflow)       │
│                                     │
│ 1. Анализирует изменение            │
│ 2. Дает рекомендации                │
│ 3. Отправляет уведомление           │
└─────────────────────────────────────┘
```

## 🎯 МОЯ РЕКОМЕНДАЦИЯ:

**Для НАЧАЛА используйте Вариант 1:**

Импортируйте **ОДИН** файл `WB_COMPLETE_BOT.json` (сейчас создам)

**Почему:**
- ✅ Проще настроить
- ✅ Нет связей между workflow
- ✅ Всё в одном месте
