# Исправления воркфлоу n8n — 2026-03-16

## Логика системы
1. Пользователь пишет нишу → **WF1 (AI Agent Bot)** ищет каналы → сохраняет в Sheets
2. Кнопка "Поиск лидов" → бот спрашивает дни и ключевые слова → **WF2 (AI Parser)** парсит лиды → отправляет отчёт
3. Кнопка "Написать лидам" → **WF3 (Smart Lead)** генерирует сообщение AI для каждого лида → отправляет
