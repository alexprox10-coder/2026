# Исправления: WF1 V4 + WF2 V5
Дата: 2026-03-17

## Логика трёх воркфлоу

**WF1** — находит Telegram-каналы по указанной нише и сохраняет в Google Sheets
**WF2** — по ключевым словам и заданным дням вытаскивает лиды из этих каналов и сохраняет в таблицу
**WF3** — Python-парсер (работает, не трогали)

---

## WF1 → V4 (`01_ai_agent_bot_V4.json`)

### Баг 1: Не сохранялся `username` канала
**Нода:** `Сохранить источники`
**Проблема:** В Google Sheets писалось 6 полей — `channel_url, channel_title, niche, score, status, added_at`. Поле `username` отсутствовало.
**Последствие:** WF2 не мог получить username канала → пытался вырезать его из URL → получал неправильные названия → парсер не находил каналы.
**Исправление:** Добавлено поле `username → {{ $json.username }}`

### Баг 2: Ключевые слова отправлялись как строка
**Нода:** `Запустить парсинг`
**Проблема:** `keywords` из диалога — это строка вида `"аренда, квартира, сниму"`. WF2 ожидает массив `["аренда", "квартира", "сниму"]`.
**Исправление:** Добавлена конвертация: `typeof keywords === "string" ? keywords.split(",").map(k => k.trim()).filter(k => k) : keywords`

### Баг 3: Таймаут 10 секунд
**Нода:** `Запустить парсинг`
**Проблема:** Timeout = 10000ms. Парсер работает дольше → WF1 падал с ошибкой "connection aborted".
**Исправление:** Timeout увеличен до 60000ms (60 сек)

## WF2 → V5 (`02_ai_parser_V5.json`)

### Баг 4: Гонка параллельных веток
**Проблема:** `Нормализовать` запускал одновременно `Получить источники` и `Получить ниши`, оба вели к `Сформировать запрос парсера`. Нода запускалась при завершении ПЕРВОЙ → вторая ещё не готова.
**Исправление:** Цепочка стала строго последовательной:
```
Нормализовать → Получить источники → Получить ниши → Сформировать запрос парсера
```

### Баг 5: Webhook ждал ответа (lastNode)
**Проблема:** `responseMode: lastNode` — WF1 отправлял запрос и ждал ответа до конца обработки. Парсинг долгий → WF1 получал timeout.
**Исправления:**
- Webhook Trigger: `responseMode` изменён на `responseNode`
- Добавлена нода `Ответить на вебхук` сразу после триггера: отвечает `{"status":"ok","message":"parsing started"}` немедленно
- WF2 продолжает работу в фоне независимо

### Баг 6: Ключевые слова не разбивались из строки
**Нода:** `Нормализовать входные данные`
**Проблема:** Если `keywords` приходило как строка — оставалось строкой, массив не создавался.
**Исправление:** Добавлена обработка: если строка — делаем `.split(',').map(trim).filter(Boolean)`

## Что делать в n8n

1. **Импортировать** `01_ai_agent_bot_V4.json` вместо текущего WF1
2. **Импортировать** `02_ai_parser_V5.json` вместо текущего WF2
3. **В Google Sheets** (вкладка `sources`) добавить колонку `username` если её нет
4. **Активировать WF2** (зелёный тумблер) перед запуском

## Оставшийся вопрос

WF1 ищет каналы через `http://172.17.0.1:5000/search_channels` (Python-сервис).
Если этот эндпоинт не реализован в WF3 — каналы не будут найдены.
Проверить: запустить `/add_niche аренда квартиры` и посмотреть вывод ноды `Поиск каналов`.
