# 🤖 Company Data Assistant - Интеллектуальный ассистент для сбора информации о компаниях

Автоматизированная система для сбора, анализа и обработки данных о компаниях с использованием AI и n8n.

## 📁 Структура проекта

### 1. `company-data-assistant-prompt.md`
Полный системный промпт для AI ассистента. Содержит:
- Описание всех доступных инструментов
- Логику работы и алгоритмы
- Правила обработки команд
- Примеры использования

### 2. `company-data-assistant-n8n-workflow.json`
Готовый workflow для импорта в n8n. Включает:
- Telegram Bot интеграцию
- AI Agent с полным промптом
- 7 инструментов для работы с данными
- Автоматические уведомления

### 3. `n8n-setup-instructions.md`
Пошаговая инструкция по настройке. Описывает:
- Импорт workflow в n8n
- Настройку Telegram Bot
- Подключение OpenAI API
- Интеграцию с Google Sheets
- Тестирование и отладку

## 🚀 Быстрый старт

1. **Импортируйте workflow**
   ```bash
   # Откройте n8n и импортируйте файл:
   company-data-assistant-n8n-workflow.json
   ```

2. **Настройте учетные данные**
   - Telegram Bot API
   - OpenAI API
   - Google Sheets API (опционально)

3. **Активируйте workflow**
   - Нажмите кнопку "Active"
   - Отправьте "привет" вашему боту в Telegram

4. **Начните работу**
   - "Собери запросы по стоматологиям в Москве"
   - "Собери сайты по запросам"
   - "Собери информацию о компаниях"

## 🛠 Возможности

### Основные функции

1. **Создание запросов** (`AgentLeadAddQuery`)
   - Генерация поисковых запросов по теме и городу
   - Сохранение в Excel/Google Sheets

2. **Сбор сайтов** (`AgentLeadAddSiteCompany`)
   - Поиск сайтов компаний через Google Maps
   - Автоматическое сохранение результатов

3. **Парсинг данных** (`AgentLeadScrapInformationCompany`)
   - Извлечение контактов с сайтов
   - Сбор email, телефонов, описаний

4. **Генерация писем** (`AgentLeadMailGenerate`)
   - Создание персонализированных черновиков
   - Сохранение в таблицу

5. **Управление данными**
   - `QuerySheets` - проверка необработанных запросов
   - `SiteCompanySheets` - список сайтов для парсинга

## 🔐 Безопасность

- Все API ключи хранятся в Credentials n8n
- Не делитесь файлом с credentials
- Используйте переменные окружения для production

## 📈 Масштабирование

Для обработки больших объемов:
1. Используйте очереди (Queue nodes в n8n)
2. Добавьте rate limiting для API
3. Настройте параллельную обработку
4. Используйте кэширование результатов

## 🐛 Отладка

Если возникли проблемы:

1. **Проверьте логи n8n**
   - Executions → последний запуск
   - Ошибки будут выделены красным

2. **Проверьте учетные данные**
   - Settings → Credentials
   - Убедитесь, что все токены валидны

3. **Тестируйте по шагам**
   - Используйте "Test workflow"
   - Проверяйте каждый узел отдельно
