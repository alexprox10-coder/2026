# 🤖 Настройка Telegram Бота для поиска лидов

## Что это?

Полностью автоматизированный Telegram бот с AI агентом для:
- ✅ Поиска компаний по запросу через Google
- ✅ Добавления сайтов компаний вручную
- ✅ Сбора контактных данных с сайтов (AI)
- ✅ Генерации персональных коммерческих предложений (AI)

**Просто пишите боту в Telegram** - он всё сделает сам!

---

## 📋 ШАГ 1: Создать Telegram бота

### 1.1 Получить токен бота

1. Откройте Telegram → найдите **@BotFather**
2. Отправьте команду: `/newbot`
3. Придумайте название: `Мой Лид-Бот`
4. Придумайте username: `my_lead_bot` (должен заканчиваться на `_bot`)
5. **Скопируйте токен** (выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

**Сохраните токен!** Он понадобится для настройки.

---

## 📋 ШАГ 2: Настроить все workflows (если ещё не сделали)

Сначала выполните **ВСЕ шаги** из файла `READY_TO_USE_SETUP.md`:

✅ Создать Google Sheets таблицу
✅ Получить API ключи (Google Custom Search + Perplexity AI)
✅ Импортировать 4 child workflows
✅ Настроить все credentials
✅ Активировать все 4 workflows

**Это обязательно!** Telegram бот работает ВМЕСТЕ с child workflows.

## 📋 ШАГ 3: Импортировать главный Telegram workflow

### 3.1 Импортировать файл

1. Откройте n8n
2. Нажмите **Workflows → Import from File**
3. Выберите файл: **`READY_MAIN_TelegramBot.json`**
4. Нажмите **Import**

### 3.2 Настроить Telegram Credentials

1. В workflow откройте любую ноду Telegram (например: **"📱 Telegram Trigger"**)
2. В поле **Credential** нажмите **Create New**
3. Выберите **Telegram API**
4. Вставьте **токен бота** (из Шага 1)
5. Нажмите **Save**

**Важно:** Все 3 ноды Telegram должны использовать ОДИНАКОВЫЙ credential!

### 3.3 Настроить OpenAI Credentials

1. Получите API ключ OpenAI: https://platform.openai.com/api-keys
2. Откройте ноду **"🧠 OpenAI GPT-4o Mini"**
3. В поле **Credential** нажмите **Create New**
4. Выберите **OpenAI API**
5. Вставьте ваш OpenAI API key
6. Нажмите **Save**

### 3.4 Настроить webhook URLs

**Это КРИТИЧЕСКИ ВАЖНО!**

1. Откройте ноду **"📋 Настройки"**
2. Замените ВСЕ 4 URL на ваши Production Webhook URLs:

```javascript
// Получите Production URLs из каждого child workflow:

webhook_search:    https://ваш-n8n.com/webhook/add-search-query
webhook_add:       https://ваш-n8n.com/webhook/add-company-site
webhook_scrape:    https://ваш-n8n.com/webhook/start-scraping
webhook_generate:  https://ваш-n8n.com/webhook/generate-proposals
```

**Как получить Production URLs:**
- Откройте каждый из 4 child workflows
- Кликните на первую ноду (Webhook)
- Скопируйте **Production URL**
- Вставьте в соответствующее поле в ноде "📋 Настройки"

### 3.5 Активировать workflow

1. В правом верхнем углу переключите **Inactive → Active**
2. Должно стать зеленым ✅

## 📋 ШАГ 4: Тестирование

### 4.1 Первый тест - Проверка соединения

1. Откройте Telegram
2. Найдите вашего бота (username который создали)
3. Нажмите **Start** или отправьте `/start`
4. Отправьте любое сообщение: `привет`

**Ожидаемый результат:**
Бот должен ответить (возможно что-то вроде "Чем могу помочь?")

✅ **Если ответил** - всё отлично! Переходите к 4.2
❌ **Если НЕ ответил** - проверьте:
- Workflow активирован?
- Telegram credential правильный?
- OpenAI credential правильный?

### 4.2 Тест - Поиск компаний

Отправьте боту:
```
найди агентства недвижимости в Благовещенске
```

**Ожидаемый результат:**
Бот должен:
1. Показать что начал поиск
2. Вызвать child workflow (поиск через Google Custom Search)
3. Вернуть результат (например: "Найдено 10 компаний, добавлено в базу данных")

**Проверка:** Откройте Google Sheets → лист CompanySites → должны появиться сайты

### 4.3 Тест - Сбор данных

Отправьте боту:
```
собери данные с найденных сайтов
```

**Ожидаемый результат:**
Бот должен:
1. Вызвать child workflow (сбор данных с Perplexity AI)
2. Обработать сайты со статусом 0
3. Вернуть результат (например: "Обработано 10 компаний")

**Проверка:** Откройте Google Sheets → лист CompanyInformation → должны появиться данные

### 4.4 Тест - Генерация писем

Отправьте боту:
```
создай коммерческие предложения для компаний
```

**Ожидаемый результат:**
Бот должен:
1. Вызвать child workflow (генерация писем с Perplexity AI)
2. Создать персональные письма для каждой компании
3. Вернуть результат (например: "Создано 8 писем")

**Проверка:** Откройте Google Sheets → лист EmailDrafts → должны появиться черновики

### 4.5 Тест - Добавление сайта вручную

Отправьте боту:
```
добавь сайт https://example-company.ru
```

**Ожидаемый результат:**
Бот должен добавить сайт в базу данных и подтвердить.

## 🔧 Если что-то не работает

### Ошибка: "Missing node to start execution"

**Причина:** Webhook URLs не настроены или неправильные

**Решение:**
1. Проверьте ноду **"📋 Настройки"**
2. Убедитесь что ВСЕ 4 URL правильные
3. URLs должны быть **Production URLs**, не Test URLs
4. URLs должны начинаться с `https://`

### Ошибка: Бот не отвечает вообще

**Решение:**
1. Проверьте что главный workflow **активирован** (зеленый)
2. Проверьте Telegram credential (токен правильный?)
3. Откройте Executions в n8n - есть ли запуски workflow?
4. Проверьте логи выполнения на ошибки

### Ошибка: "OpenAI API error"

**Решение:**
1. Проверьте OpenAI credential
2. Проверьте баланс OpenAI: https://platform.openai.com/usage
3. Убедитесь что API key активен

### Ошибка: Child workflows не вызываются

**Решение:**
1. Убедитесь что ВСЕ 4 child workflows **активированы**
2. Проверьте webhook URLs в ноде "📋 Настройки"
3. Попробуйте вызвать child workflow напрямую через curl (см. READY_TO_USE_SETUP.md)

### AI Agent вызывает неправильный tool

**Решение:**
1. Переформулируйте запрос более чётко
2. Примеры:
   - ❌ "найди компании" → ✅ "найди строительные компании в Благовещенске"
   - ❌ "собери" → ✅ "собери данные с найденных сайтов"

## 📊 Полный workflow процесс

```
Вы пишете боту в Telegram:
"найди агентства недвижимости в Благовещенске"
          ↓
AI Agent понимает запрос и вызывает tool "search_companies"
          ↓
Tool отправляет HTTP запрос на child workflow 01 (Google Custom Search)
          ↓
Child workflow ищет компании в Google и сохраняет в Google Sheets
          ↓
Результат возвращается боту
          ↓
Бот отвечает вам: "Найдено 10 компаний!"
```

## ⚙️ Дополнительные настройки

### Изменить системное сообщение AI Agent

Откройте ноду **"🤖 AI Agent"** → в Options → System Message

Можете настроить:
- Стиль общения (формальный/неформальный)
- Язык ответов
- Дополнительные инструкции

### Изменить модель AI

По умолчанию используется **gpt-4o-mini** (быстрая и дешёвая).

Можно изменить на:
- **gpt-4o** - более умная, дороже
- **gpt-3.5-turbo** - дешевле, проще

Откройте ноду **"🧠 OpenAI GPT-4o Mini"** → измените Model Name

### Добавить больше tools

Вы можете добавить дополнительные HTTP Request tools для:
- Поиска по конкретным сайтам
- Интеграции с CRM
- Отправки email через API
