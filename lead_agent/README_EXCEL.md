# 🤖 Интеллектуальный Агент для Сбора Лидов (Excel версия)

Автоматизированный ассистент на базе Claude AI для сбора информации о компаниях с сохранением в **Excel-файлы**.

## ✨ Отличия от Google Sheets версии

| Параметр | Google Sheets (`agent.py`) | Excel (`agent_excel.py`) |
|----------|---------------------------|--------------------------|
| Хранение данных | Google Sheets онлайн | Локальный Excel файл |
| Требуется интернет | Да (для синхронизации) | Нет (только для парсинга) |
| Настройка | Google Service Account | Нет дополнительной настройки |
| Скорость | Медленнее (API запросы) | Быстрее (локальный файл) |
| Совместная работа | Да (онлайн) | Нет (локальный файл) |
| Резервное копирование | Автоматическое (Google) | Ручное |

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd lead_agent
pip install -r requirements.txt
```

**Новые зависимости для Excel:**
- `openpyxl` - работа с Excel файлами
- `pandas` - обработка данных

### 2. Настройка .env

```bash
cp .env.example .env
nano .env
```

**Обязательные параметры:**
```env
# Anthropic API ключ
ANTHROPIC_API_KEY=sk-ant-xxxxx

# Путь к Excel файлу (будет создан автоматически)
EXCEL_FILE_PATH=data/lead_data.xlsx

# Google Maps API
GOOGLE_MAPS_API_KEY=AIzaSyxxxxx

# Telegram Bot (опционально)
TELEGRAM_BOT_TOKEN=123456:ABCxxx
TELEGRAM_CHAT_ID=123456789
```

### 3. Запуск агента

```bash
python agent_excel.py
```

## 🔧 Доступные инструменты

Агент использует те же инструменты что и Google Sheets версия:

1. **AgentLeadAddQuery** - создание запросов
2. **AgentLeadAddSiteCompany** - сбор сайтов (200-300 без дублей!)
3. **AgentLeadScrapInformationCompany** - парсинг сайтов
4. **AgentLeadMailGenerate** - генерация КП
5. **QuerySheets** - проверка статуса запросов
6. **SiteCompanySheets** - проверка статуса сайтов
7. **TelegramMessage** - уведомления

## 📁 Работа с Excel файлом

### Открытие в Excel/LibreOffice

```bash
# Linux
libreoffice data/lead_data.xlsx

# macOS
open data/lead_data.xlsx

# Windows
start data/lead_data.xlsx
```

### Экспорт в другие форматы

```python
import pandas as pd

# Чтение данных
df = pd.read_excel('data/lead_data.xlsx', sheet_name='КОМПАНИИ')

# Экспорт в CSV
df.to_csv('companies.csv', index=False, encoding='utf-8-sig')

# Экспорт в JSON
df.to_json('companies.json', orient='records', force_ascii=False)
```

### Резервное копирование

```bash
# Создание копии
cp data/lead_data.xlsx data/backup_$(date +%Y%m%d).xlsx

# Архивирование
tar -czf lead_data_$(date +%Y%m%d).tar.gz data/
```

## 🐛 Устранение неполадок

### Excel файл заблокирован

```
Ошибка: Permission denied
```

**Решение:** Закройте файл в Excel/LibreOffice

### Не хватает памяти

```
MemoryError
```

**Решение:** Уменьшите лимиты обработки или используйте более мощный компьютер

### Файл повреждён

```
BadZipFile error
```

**Решение:** Удалите `data/lead_data.xlsx`, агент создаст новый

## 🆚 Когда использовать какую версию?

### Используйте Excel (`agent_excel.py`):
- ✅ Работаете локально
- ✅ Нужна максимальная скорость
- ✅ Не требуется совместная работа
- ✅ Хотите минимум настроек

### Используйте Google Sheets (`agent.py`):
- ✅ Нужна совместная работа команды
- ✅ Доступ с разных устройств
- ✅ Автоматическое резервное копирование
- ✅ Интеграция с другими Google сервисами

## 📝 Часто задаваемые вопросы

**Q: Можно ли использовать оба варианта одновременно?**
A: Да, но данные не синхронизируются автоматически.

**Q: Можно ли импортировать данные из Google Sheets в Excel?**
A: Да, скачайте Google Sheets как .xlsx и укажите путь в `EXCEL_FILE_PATH`.

**Q: Работает ли на macOS/Linux?**
A: Да, openpyxl кроссплатформенная библиотека.

**Q: Какой максимальный размер Excel файла?**
A: Практически не ограничен (зависит от RAM), но рекомендуется до 10,000 строк на лист.
