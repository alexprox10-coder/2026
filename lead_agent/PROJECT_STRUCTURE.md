## Описание файлов

### Главные файлы

#### `agent.py`
Основной файл агента, содержит:
- Класс `LeadCollectionAgent` - главный агент
- Интеграцию с Claude AI (Anthropic API)
- Определение всех инструментов (tools)
- Логику обработки сообщений пользователя
- Интерактивный режим работы

**Ключевые методы:**
- `process_message()` - обработка сообщений пользователя
- `_execute_tool()` - выполнение вызовов инструментов
- `run_interactive()` - интерактивный режим

#### `requirements.txt`
Список всех Python зависимостей:
- `anthropic` - Claude AI SDK
- `gspread` - Google Sheets API
- `python-telegram-bot` - Telegram Bot API
- `requests`, `beautifulsoup4` - веб-скрейпинг
- И другие

### Модули

#### `modules/google_sheets.py`
Класс `GoogleSheetsManager` для работы с Google Sheets:
- Подключение к Google Sheets API
- Работа с 4 листами: ЗАПРОСЫ, САЙТЫ, КОМПАНИИ, ПИСЬМА
- Методы добавления/получения данных
- Обновление статусов записей

**Основные методы:**
- `add_queries()` - добавить запросы
- `get_queries_with_status()` - получить запросы по статусу
- `add_sites()` - добавить сайты компаний
- `add_companies()` - добавить информацию о компаниях
- `add_letters()` - добавить черновики писем
- `update_query_status()` - обновить статус запроса
- `update_site_status()` - обновить статус сайта

#### `modules/telegram_bot.py`
Класс `TelegramNotifier` для отправки уведомлений:
- Асинхронная и синхронная отправка сообщений
- Различные типы уведомлений (старт, прогресс, успех, ошибка)
- HTML форматирование сообщений

**Основные методы:**
- `send_message()` - отправить сообщение
- `send_start_notification()` - уведомление о начале работы
- `send_success_notification()` - уведомление об успехе
- `send_error_notification()` - уведомление об ошибке

#### `modules/google_maps.py`
Класс `GoogleMapsParser` для работы с Google Maps API:
- Поиск компаний по запросам
- Получение детальной информации о местах
- Геокодирование локаций
- Обработка пагинации результатов

**Основные методы:**
- `search_places()` - поиск мест по запросу
- `get_place_details()` - детальная информация о месте

#### `modules/scraper.py`
Класс `WebScraper` для парсинга сайтов:
- Извлечение контактной информации
- Парсинг email адресов и телефонов
- Получение описаний и услуг компаний
- Поиск социальных сетей
- Обработка страниц контактов

**Основные методы:**
- `scrape_company_info()` - парсинг информации о компании
- `scrape_contact_page()` - парсинг страницы контактов
- `_extract_emails()` - извлечение email адресов
- `_extract_phones()` - извлечение телефонов

## Инструменты агента

Агент использует следующие инструменты через Claude AI Function Calling:

### 1. TelegramMessage
**Назначение:** Отправка уведомлений в Telegram
**Параметры:**
- `message` - текст сообщения
- `message_type` - тип (start, progress, success, error)

### 2. QuerySheets
**Назначение:** Получение необработанных запросов из Google Sheets
**Параметры:**
- `limit` - максимальное количество запросов (по умолчанию 10)

### 3. AgentLeadAddQuery
**Назначение:** Создание и сохранение поисковых запросов
**Параметры:**
- `request` - описание задачи

**Пример:** "Подготовить запросы на тему стоматологии, город Москва"

### 4. SiteCompanySheets
**Назначение:** Получение сайтов компаний для обработки
**Параметры:**
- `limit` - максимальное количество сайтов (по умолчанию 10)

### 5. AgentLeadAddSiteCompany
**Назначение:** Сбор сайтов компаний из Google Maps
**Параметры:**
- `max_queries` - количество запросов для обработки (по умолчанию 5)

### 6. AgentLeadScrapInformationCompany
**Назначение:** Парсинг информации с сайтов компаний
**Параметры:**
- `max_sites` - количество сайтов для обработки (по умолчанию 10)

### 7. AgentLeadMailGenerate
**Назначение:** Создание персонализированных писем
**Параметры:**
- `max_companies` - количество писем для создания (по умолчанию 10)

## Поток данных

```
1. Пользователь → Команда
                ↓
2. Claude AI → Понимание намерения
                ↓
3. Агент → Вызов инструментов
                ↓
4. Инструменты → Выполнение задач
                ↓
5. Google Sheets ← Сохранение данных
                ↓
6. Telegram ← Уведомления
                ↓
7. Пользователь ← Результат
```

## Статусы обработки

### Запросы (ЗАПРОСЫ)
- `0` - не обработан
- `1` - обработан (сайты собраны)

### Сайты (САЙТЫ)
- `0` - данные не собраны
- `1` - данные собраны

### Письма (ПИСЬМА)
- `0` - не отправлено
- `1` - отправлено

## Безопасность

### Файлы, которые НЕ должны попадать в Git:
- `.env` - содержит API ключи
- `config/google_credentials.json` - Google сервисный аккаунт
- `logs/*.log` - файлы логов
- `venv/` - виртуальное окружение

### Защита секретов:
- Используйте `.env` файлы
- Не коммитьте credentials
- Храните резервные копии ключей в защищённом месте
- Регулярно ротируйте API ключи
