# 🤖 Интеллектуальный Агент для Сбора Информации о Компаниях

Автоматизированный ассистент на базе Claude AI для сбора лидов и информации о компаниях в России. Агент работает с Google Sheets, Google Maps API и автоматически парсит данные с сайтов компаний.

## ✨ Возможности

- 🔍 **Генерация поисковых запросов** - Claude AI создаёт оптимальные запросы для поиска компаний
- 🗺️ **Сбор данных из Google Maps** - автоматический поиск компаний по заданным критериям
- 🌐 **Парсинг сайтов** - извлечение контактной информации, услуг, описаний
- 📊 **Интеграция с Google Sheets** - все данные сохраняются в структурированном виде
- 📱 **Telegram уведомления** - мгновенные оповещения о статусе работы
- ✉️ **Генерация персонализированных писем** - Claude создаёт уникальные письма для каждой компании

## 📋 Структура Google Sheets

Агент работает с 4 листами:

### 1. ЗАПРОСЫ
Хранит поисковые запросы для Google Maps
- ID, Дата создания, Тема, Город, Запрос, Статус, Дата обработки

### 2. САЙТЫ
Список найденных компаний с их сайтами
- ID, Дата добавления, Название компании, Сайт, Телефон, Адрес, Город, Категория, Статус сбора данных, ID запроса

### 3. КОМПАНИИ
Детальная информация о компаниях
- ID, Дата сбора, Название компании, Сайт, Email, Телефон, Адрес, Описание, Услуги, Контактное лицо, Соц. сети, ID сайта

### 4. ПИСЬМА
Черновики писем для компаний
- ID, Дата создания, Название компании, Email, Тема письма, Текст письма, Статус отправки, ID компании

## 🚀 Установка

### 1. Клонирование репозитория

```bash
cd lead_agent
```

### 2. Создание виртуального окружения

```bash
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Заполните `.env` файл:

```env
# Anthropic API (обязательно)
ANTHROPIC_API_KEY=your_anthropic_api_key_here

# Google Sheets (обязательно)
GOOGLE_SHEETS_ID=17Ll6-lvbJTGix5Y6uwh2Glr8CNT6FktnicRsuOWdhqA
GOOGLE_CREDENTIALS_FILE=config/google_credentials.json

# Telegram (опционально)
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
TELEGRAM_CHAT_ID=your_telegram_chat_id_here

# Google Maps API (обязательно)
GOOGLE_MAPS_API_KEY=your_google_maps_api_key_here

# Настройки
TIMEZONE=Europe/Moscow
REGION=Россия
LOG_LEVEL=INFO
```

### 5. Настройка Google Sheets API

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте новый проект или выберите существующий
3. Включите **Google Sheets API** и **Google Drive API**
4. Создайте Service Account:
   - IAM & Admin → Service Accounts → Create Service Account
   - Скачайте JSON ключ
5. Переименуйте скачанный файл в `google_credentials.json`
6. Поместите его в `lead_agent/config/google_credentials.json`
7. Откройте вашу Google таблицу и дайте доступ service account email (из JSON файла)

### 6. Получение API ключей

#### Anthropic API
1. Зарегистрируйтесь на [anthropic.com](https://www.anthropic.com/)
2. Перейдите в [console.anthropic.com](https://console.anthropic.com/)
3. Создайте API ключ в разделе API Keys

#### Google Maps API
1. В [Google Cloud Console](https://console.cloud.google.com/)
2. APIs & Services → Credentials
3. Create Credentials → API Key
4. Включите следующие API:
   - Places API
   - Geocoding API
   - Maps JavaScript API

#### Telegram Bot (опционально)
1. Напишите [@BotFather](https://t.me/botfather) в Telegram
2. Создайте бота командой `/newbot`
3. Получите токен бота
4. Узнайте свой Chat ID через [@userinfobot](https://t.me/userinfobot)

## 🛠️ Доступные инструменты

Агент автоматически использует следующие инструменты:

### 1. TelegramMessage
Отправляет уведомления в Telegram о статусе работы

Получает список необработанных запросов из Google Sheets

Генерирует и сохраняет поисковые запросы с помощью Claude AI

Получает список сайтов компаний для обработки

Парсит детальную информацию с сайтов компаний

### 7. AgentLeadMailGenerate
Создаёт персонализированные письма для компаний

## 📊 Логирование

Все логи сохраняются в файл `logs/agent.log` и выводятся в консоль.

Уровни логирования:
- **INFO** - основная информация о работе
- **WARNING** - предупреждения
- **ERROR** - ошибки

## 🔧 Устранение неполадок

### Ошибка "ANTHROPIC_API_KEY не настроен"
- Проверьте, что `.env` файл существует
- Убедитесь, что `ANTHROPIC_API_KEY` заполнен

### Ошибка подключения к Google Sheets
- Проверьте, что `google_credentials.json` находится в `config/`
- Убедитесь, что service account имеет доступ к таблице
- Проверьте правильность `GOOGLE_SHEETS_ID`

### Telegram не отправляет сообщения
- Проверьте токен бота и Chat ID
- Убедитесь, что вы написали боту первое сообщение `/start`

### Google Maps не находит компании
- Проверьте, что API ключ активен
- Убедитесь, что включены нужные API (Places, Geocoding)
- Проверьте лимиты использования API
