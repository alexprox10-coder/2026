# Исправление проблемы: В таблицу приходит текст запроса вместо компаний

## 🔍 Диагностика проблемы

### Что видит пользователь

**Скриншот показывает:**
```
| Запросы | contentArray | query | status | message |
|---------|--------------|-------|--------|---------|
| ... | ... | Подготовить запросы на тему строительные компании, город Москва | prepared | Запрос подготовлен: ... |
```

❌ **Проблема:** Возвращается текст запроса, а не список компаний

### Корневая причина

1. **Workflow разделен на 2 этапа:**
   - **Этап 1** (AgentLeadAddQuery): Добавляет запрос в таблицу → возвращает текст запроса
   - **Этап 2** (Cycle 2): Ищет компании каждые 10 минут → сохраняет в другую вкладку

2. **Найдены критические проблемы:**
   - ❌ Cycle 2 отключен (`"active": false`)
   - ❌ API ключ Perplexity не настроен (`YOUR_PERPLEXITY_API_KEY_HERE`)
   - ❌ Пользователь ждет немедленного результата, а не отложенного

## ✅ Решение

### Файлы с исправлением

   - Работает за 1-2 секунды

2. **`SOLUTION_IMMEDIATE_COMPANY_SEARCH.md`**

## 📋 Инструкция по установке

### Вариант 1: Импорт в n8n (РЕКОМЕНДУЕТСЯ)

1. **Откройте n8n**
2. **Workflows → Import from File**
3. **Выберите файл:** `child_workflow_01_AgentLeadAddQuery_FIXED.json`
4. **Настройте API ключ:**
   - Откройте узел "Perplexity - Поиск компаний"
   - Замените `YOUR_PERPLEXITY_API_KEY_HERE` на ваш реальный API ключ
   - Получить ключ: https://www.perplexity.ai/settings/api
5. **Сохраните workflow**
6. **Активируйте** (кнопка "Active")
7. **Протестируйте:**
   ```json
   {
     "query": "строительные компании Москва"
   }
   ```

### Вариант 2: Активировать Cycle 2 (если есть API ключ)

1. **Откройте файл:** `cycle2_find_company_websites.json`
2. **Найдите строку 85:** `"Bearer YOUR_PERPLEXITY_API_KEY_HERE"`
3. **Замените на:** `"Bearer pplx-ВАШ_КЛЮЧ"`
4. **Найдите строку 403:** `"active": false`
5. **Замените на:** `"active": true`
6. **Импортируйте в n8n**
7. **Активируйте workflow**

Теперь Cycle 2 будет автоматически искать компании каждые 10 минут.

## 🔧 Настройка API ключей

### Perplexity AI (рекомендуется для поиска)

1. Регистрация: https://www.perplexity.ai/
2. Settings → API Keys
3. Create New Key
4. Скопируйте ключ (начинается с `pplx-`)
5. Стоимость: ~$0.001-0.005 за запрос

### Claude API (универсальный AI)

1. Регистрация: https://console.anthropic.com/
2. API Keys → Create Key
3. Скопируйте ключ (начинается с `sk-ant-`)
4. Стоимость: ~$0.003-0.015 за запрос

### OpenAI API (альтернатива)

1. Регистрация: https://platform.openai.com/
2. API Keys → Create new secret key
3. Скопируйте ключ (начинается с `sk-`)
4. Стоимость: ~$0.01-0.03 за запрос

## ❓ FAQ

### Q: Нужно ли удалять старый workflow?

**A:** Нет, можно оставить оба. Новый workflow имеет суффикс `_FIXED` в названии.

### Q: Что делать если компании не найдены?

**A:** Workflow вернет:
```json
{
  "success": false,
  "message": "Компании не найдены для запроса: ...",
  "companies_found": 0
}
```

Попробуйте:
- Уточнить запрос (добавить город, сферу деятельности)
- Проверить API ключ
- Проверить лимиты API

### Q: Можно ли искать компании из других стран?

**A:** Да, просто укажите город:
```json
{
  "city": "New York",
  "theme": "construction"
}
```

### Q: Сколько стоит один поиск?

**A:**
- Perplexity: $0.001-0.005
- Claude: $0.003-0.015
- OpenAI: $0.01-0.03
- Google Custom Search: Бесплатно (до 100 запросов/день)

### Q: Как часто можно запускать поиск?

**A:**
- Perplexity: до 1000 запросов/минуту (платный план)
- Claude: до 50 запросов/минуту
- OpenAI: до 10000 запросов/минуту (зависит от плана)

### Q: Cycle 2 всё ещё нужен?

**A:** Нет, если используете новый workflow. Но можно оставить для фоновой обработки больших объемов запросов.
