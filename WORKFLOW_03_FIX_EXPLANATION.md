## 📋 Основные узлы workflow

### 1. Schedule Trigger - "Каждые 5 минут"
- Запускает workflow автоматически каждые 5 минут
- Ищет новые необработанные компании

### 2. Google Sheets Read - "Прочитать компании"
- Читает из листа "Компании" (gid=0)
- Фильтр: `Статус получения данных = 0`
- Возвращает только компании, которые ещё не обработаны

### 3. IF Node - "Есть компании?"
- Проверяет: найдены ли компании для обработки
- Если НЕТ → завершить workflow
- Если ДА → перейти к циклу

### 4. Split In Batches - "Цикл по компаниям"
- Обрабатывает компании по одной
- Batch size = 1 (по 1 компании за раз)
- Предотвращает перегрузку API

### 5. HTTP Request (Claude API) - "Claude - Парсинг сайта"

**Запрос:**
```json
{
  "model": "claude-3-5-sonnet-20241022",
  "max_tokens": 2048,
  "messages": [
    {
      "role": "user",
      "content": "Посети сайт {{ $json.Сайт }} и извлеки следующую информацию о компании:\n\n1. Телефон (все найденные номера через запятую)\n2. Email (все найденные email через запятую)\n3. Краткое описание компании (1-2 предложения о чем компания)\n\nВерни результат СТРОГО в JSON формате без дополнительных пояснений:\n{\n  \"phone\": \"телефон или пусто\",\n  \"email\": \"email или пусто\",\n  \"description\": \"описание компании\"\n}\n\nВАЖНО:\n- Если данные не найдены, пиши пустую строку\n- Не добавляй комментариев, только JSON\n- Ищи контакты на главной странице и странице 'Контакты'\n- Для описания используй информацию из раздела 'О компании' или главной страницы"
    }
  ]
}
```

**Ответ:**
```json
{
  "content": [
    {
      "text": "{\n  \"phone\": \"+7 495 123-45-67\",\n  \"email\": \"info@example.com\",\n  \"description\": \"Строительная компания полного цикла\"\n}"
    }
  ]
}
```

### 6. Code Node - "Извлечь данные"

```javascript
// Извлечь JSON из ответа Claude
const response = $input.first().json;
const content = response.content[0].text;

// Попытаться распарсить JSON
let companyData = {
  phone: '',
  email: '',
  description: ''
};

try {
  // Извлечь JSON из возможного markdown блока
  const jsonMatch = content.match(/\{[\s\S]*\}/);
  if (jsonMatch) {
    companyData = JSON.parse(jsonMatch[0]);
  }
} catch (error) {
  console.error('Error parsing JSON:', error);
}

// Получить данные из предыдущего узла
const previousData = $('Цикл по компаниям').item.json;

return {
  json: {
    row_number: previousData.row_number || 0,
    website: previousData.Сайт || previousData.website || '',
    company_name: previousData.Компания || previousData.company_name || '',
    phone: companyData.phone || '',
    email: companyData.email || '',
    description: companyData.description || '',
    status: 1
  }
};
```

### 7. Google Sheets Update - "Обновить Google Sheets"

**Операция:** UPDATE
**Matching Column:** Сайт (находит строку по URL)
**Обновляемые колонки:**
- `phone` = найденный телефон
- `email` = найденный email
- `description` = описание компании
- `Статус получения данных` = 1 (обработано)

### 8. Wait - "Пауза 3 сек"
- Задержка 3 секунды между обработкой компаний
- Предотвращает rate limiting Google Sheets API
- Предотвращает перегрузку Claude API

### 9. Set - "Лог успеха"
- Логирует результат обработки
- Показывает найденные телефон и email
- Помогает в отладке

## ⚙️ Настройки производительности

### Частота запуска

По умолчанию: **каждые 5 минут**

Изменить можно в узле "Каждые 5 минут":
```json
{
  "parameters": {
    "rule": {
      "interval": [
        {
          "field": "minutes",
          "minutesInterval": 5  // ← Изменить на 1, 2, 10, 15, etc
        }
      ]
    }
  }
}
```

**Рекомендации:**
- **1-2 минуты:** Для быстрого сбора (если мало компаний)
- **5 минут:** Оптимальный баланс
- **10-15 минут:** Для экономии API запросов

### Размер батча

По умолчанию: **1 компания за раз**

Изменить можно в узле "Цикл по компаниям":
```json
{
  "parameters": {
    "options": {
      "batchSize": 1  // ← Изменить на 2, 3, 5
    }
  }
}
```

**Внимание:**
- При увеличении batch size нагрузка на API увеличивается
- Рекомендуется оставить `batchSize: 1` для стабильности

### Пауза между запросами

По умолчанию: **3 секунды**

Изменить можно в узле "Пауза 3 сек":
```json
{
  "parameters": {
    "amount": 3,  // ← Изменить на 1, 2, 5
    "unit": "seconds"
  }
}
```

## 💰 Стоимость

### Claude API (Anthropic)

**Модель:** `claude-3-5-sonnet-20241022`

**Цены:**
- Input: $3 за 1M токенов
- Output: $15 за 1M токенов

**Средний запрос:**
- Input: ~200 токенов (промпт + URL)
- Output: ~100 токенов (JSON с данными)

**Стоимость 1 запроса:** ~$0.002 (0.2 цента)

**Пример:**
- 100 компаний: ~$0.20
- 1000 компаний: ~$2.00
- 10000 компаний: ~$20.00

### Google Sheets API

**Бесплатно:**
- До 300 запросов в минуту на пользователя
- До 100 запросов в 100 секунд на пользователя

**Наш workflow:**
- 1 Read + 1 Update = 2 запроса на компанию
- При паузе 3 сек: ~20 компаний в минуту = 40 запросов/мин
- **Вывод:** Всё в рамках бесплатных лимитов

## 🐛 Решение проблем

### Проблема 1: Workflow не запускается автоматически

**Причина:** Workflow не активирован

**Решение:**
1. Откройте workflow в n8n
2. Нажмите кнопку **Active**
3. Должна появиться галочка ✅

### Проблема 2: Ошибка "Invalid credentials"

**Причина:** Не настроены или устарели credentials

**Решение для Google Sheets:**
1. **Settings** → **Credentials**
2. Найдите "ТАБЛИЦА ПАРСЕР ВК + ОТПРАВКА КП"
3. **Reconnect** → Пройдите OAuth авторизацию

**Решение для Claude API:**
1. **Settings** → **Credentials**
2. Найдите "Anthropic account"
3. Проверьте API ключ (должен начинаться с `sk-ant-`)
4. Если ключ устарел, создайте новый на https://console.anthropic.com/

### Проблема 3: Данные не обновляются в Google Sheets

**Причина:** Неверное название колонки "Сайт" или workflow не может найти строку

**Решение:**
1. Проверьте что в Google Sheets есть колонка **"Сайт"** (с заглавной С)
2. Проверьте что URL в колонке "Сайт" точно совпадает
3. Попробуйте запустить workflow вручную и посмотрите логи

### Проблема 4: Claude возвращает пустые данные

**Причина:** Сайт не доступен или Claude не может его парсить

**Решение:**
1. Проверьте что URL валиден и доступен
2. Попробуйте открыть URL в браузере
3. Некоторые сайты блокируют парсинг - для них данные останутся пустыми

### Проблема 5: Rate limiting от Google API

**Ошибка:** "The service is receiving too many requests from you"

**Решение:**
1. Увеличьте паузу между запросами (в узле "Пауза 3 сек")
2. Уменьшите частоту запуска workflow (например, с 5 минут на 10)
3. Проверьте что нет других workflows которые также используют Google Sheets API

### Проблема 6: Rate limiting от Claude API

**Ошибка:** "Rate limit exceeded"

**Решение:**
1. Увеличьте паузу между запросами
2. Проверьте ваш план Anthropic API (есть ли лимиты)
3. Уменьшите частоту запуска workflow
