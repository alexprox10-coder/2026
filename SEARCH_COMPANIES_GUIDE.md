# 🔍 Автоматический поиск сайтов компаний

## Проблема:
Вы хотите, чтобы система автоматически **искала сайты компаний** по запросу, а не добавляла их вручную.

## Решение:
Создан новый workflow: **child_workflow_01_AgentLeadAddQuery_FIXED.json**

---

## 🎯 Как это работает:

### Шаг 1: Поисковый запрос
Вы отправляете запрос через API:
```json
{
  "query": "агентство недвижимости",
  "city": "Благовещенск",
  "region": "Амурская область",
  "industry": "недвижимость"
}
```

### Шаг 2: Автоматический поиск
Workflow ищет сайты компаний через Google (используя SerpAPI)

### Шаг 3: Фильтрация
Исключаются нерелевантные сайты:
- ❌ Социальные сети (VK, Instagram, Facebook)
- ❌ Доски объявлений (Avito, 2GIS)
- ❌ Поисковики, справочники

### Шаг 4: Сохранение
Найденные сайты добавляются в CompanySites со статусом 0

### Шаг 5: Обработка
Workflow `child_workflow_03` автоматически собирает с них данные

---

## 📦 Полный цикл работы системы:

```
1. child_workflow_01 → Ищет сайты → Добавляет в CompanySites (Status=0)
2. child_workflow_03 → Читает Status=0 → Собирает данные → Status=2
3. CompanyInformation → Готовые контакты компаний
```

## 🔑 Настройка SerpAPI (рекомендуется)

### Что такое SerpAPI?
API для поиска в Google без блокировок и капчи.

### Получить ключ:
```
https://serpapi.com/users/sign_up
```

**Бесплатный план:**
- 100 поисковых запросов в месяц
- Достаточно для теста

**Платный план:**
- От $50/месяц за 5000 запросов
- Для серьезного использования

### Настройка в n8n:

1. **Создайте credential:**
   - Settings → Credentials → Add Credential
   - Выберите: "HTTP Query Auth"
   - Name: `api_key`
   - Value: ваш ключ SerpAPI

2. **В workflow:**
   - Откройте узел "🔍 Google Search (SerpAPI)"
   - Подключите credential

## 💡 Альтернатива: Бесплатный поиск (без API)

Если не хотите платить за SerpAPI, есть бесплатные варианты:

### Вариант 1: Ручной импорт из 2GIS

1. Откройте 2GIS: https://2gis.ru
2. Найдите "агентства недвижимости Благовещенск"
3. Экспортируйте список (расширения браузера или вручную)
4. Импортируйте в Google Sheets

### Вариант 2: Яндекс.Карты API (бесплатно)

API Яндекс.Карт бесплатен до 25 000 запросов/день.

Получить ключ:
```
https://developer.tech.yandex.ru
```

Нужно модифицировать workflow (заменить SerpAPI на Yandex Maps API).

### Вариант 3: Google Custom Search API

Google предоставляет 100 бесплатных запросов/день.

Получить ключ:
```
https://developers.google.com/custom-search/v1/introduction
```

## 🚀 Быстрый старт (с SerpAPI):

### Шаг 1: Получите ключ SerpAPI
```
https://serpapi.com/users/sign_up
```

### Шаг 2: Импортируйте workflow
```
child_workflow_01_AgentLeadAddQuery_FIXED.json
```

### Шаг 3: Настройте credentials
- Добавьте HTTP Query Auth
- api_key = ваш ключ

### Шаг 4: Замените Google Sheet ID
- В узле "💾 Save to CompanySites"
- YOUR_GOOGLE_SHEET_ID_HERE → ваш ID

### Шаг 5: Активируйте workflow

### Шаг 6: Отправьте тестовый запрос

```bash
curl -X POST https://your-n8n.com/webhook/add-search-query \
  -H "Content-Type: application/json" \
  -d '{
    "query": "агентство недвижимости",
    "city": "Благовещенск",
    "region": "Амурская область",
    "industry": "недвижимость"
  }'
```

### Шаг 7: Проверьте результат

Откройте Google Sheets → CompanySites
Должны появиться новые строки со статусом 0.

### Шаг 8: Запустите сбор данных

Workflow `child_workflow_03` автоматически обработает найденные сайты.

## 📈 Мониторинг:

### Проверить найденные сайты:
```sql
SELECT * FROM CompanySites
WHERE Source = 'google_search'
AND Status = 0
```

В Google Sheets:
```
Фильтр → Source = google_search → Status = 0
```

### Статистика:
- Status = 0: Найдены, ожидают обработки
- Status = 1: В процессе сбора данных
- Status = 2: Данные собраны успешно
- Status = 3: Ошибка при сборе

## ⚠️ Ограничения:

### SerpAPI (бесплатный план):
- 100 запросов/месяц
- 1 запрос = 1 поисковая фраза
- ~10 сайтов за запрос

**Итого:** ~1000 сайтов/месяц бесплатно

### Качество результатов:
- Google блокирует некоторые запросы
- Не все компании имеют сайты
- Некоторые сайты могут быть неактивны

## 📞 Частые вопросы:

### Q: Нужно ли платить за SerpAPI?
**A:** Для теста - нет (100 запросов/месяц бесплатно). Для постоянной работы - желательно.

### Q: Можно ли без SerpAPI?
**A:** Да! Используйте:
- Яндекс.Карты API (бесплатно)
- Google Custom Search (100/день бесплатно)
- Ручной импорт из 2GIS

### Q: Сколько сайтов найдется?
**A:** Зависит от запроса. Обычно 5-15 сайтов за запрос.

### Q: Как часто запускать поиск?
**A:** Раз в неделю достаточно. Новые компании появляются не так часто.
