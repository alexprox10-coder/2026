# 🏠 Rental Property Parser

Автоматический парсер объявлений об аренде квартир с **Cian.ru**, **Yandex.Realty** и **Avito.ru** с интеграцией в n8n и Telegram.

## 📋 Возможности

✅ **Парсинг трех главных площадок**:
- Cian.ru
- Yandex.Realty
- Avito.ru

✅ **Только долгосрочная аренда** (исключая посуточную аренду и продажу)

✅ **Извлечение данных**:
- Ссылка на объявление
- Номер телефона
- Цена, адрес, количество комнат, площадь
- Этаж и общее количество этажей

✅ **Защита от банов**:
- Ротация прокси-серверов
- Случайные User-Agent
- Rate limiting (задержки между запросами)
- Имитация человеческого поведения

✅ **Telegram-бот для менеджеров**:
- Получение свежих объявлений по команде `/get`
- Автоматические уведомления о новых объявлениях
- Статистика по базе данных
- Настройка фильтров

✅ **Автоматизация через n8n**:
- **Unified Workflow** - все 3 платформы в одном workflow ⭐
- Параллельный парсинг Cian, Yandex и Avito
- Автоматический парсинг каждые 4 часа
- Извлечение номеров телефонов
- Отправка в Telegram с эмодзи для каждой платформы
- Сохранение в Google Sheets
- Webhook для ручного запуска
- Статистика и уведомления в реальном времени

✅ **Дедупликация**:
- Каждое объявление отправляется только один раз
- Система маркеров для отслеживания отправленных объявлений

✅ **Интеграция автодозвона** (опционально)

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd rental_parser
pip install -r requirements.txt
```

### 2. Настройка конфигурации

Скопируйте файл примера и отредактируйте его:

```bash
cp .env.example .env
nano .env
```

Заполните обязательные параметры:
```env
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_CHAT_ID=your_chat_id_here
```

### 3. Настройка прокси (опционально, но рекомендуется)

```bash
cp proxies.example.txt proxies.txt
nano proxies.txt
```

Добавьте свои прокси в формате:
```
http://user:pass@proxy1.example.com:8080
http://user:pass@proxy2.example.com:8080
```

### 4. Запуск парсера

**Однократный запуск:**
```bash
python main.py --max-pages 5
```

**С указанием конкретных платформ:**
```bash
python main.py --platforms cian yandex --max-pages 3
```

**Извлечение номеров телефонов:**
```bash
python main.py --extract-phones --phone-limit 20
```

**Статистика:**
```bash
python main.py --stats
```

### 5. Запуск Telegram-бота

```bash
cd bot
python telegram_bot.py
```

Команды бота:
- `/start` - Регистрация
- `/get [N]` - Получить N новых объявлений
- `/stats` - Статистика базы данных
- `/help` - Справка

### 6. Импорт n8n workflow

**Доступны два варианта:**

#### Рабочий Workflow ⭐ (Исправленная версия)

**Используйте файл: `rental_parser_unified_fixed.json`**

1. Откройте n8n
2. Создайте новый workflow
3. **Импортируйте файл `rental_parser_unified_fixed.json`** ⚠️
4. Настройте креденшиалы:
   - Telegram API (обязательно)
   - Google Sheets OAuth2 (опционально)
5. Установите переменные окружения в n8n:
   - `TELEGRAM_CHAT_ID` - ваш Telegram ID
   - `GOOGLE_SHEET_ID` - ID Google таблицы (опционально)
   - `AUTO_DIAL_WEBHOOK_URL` - webhook для автодозвона (опционально)
6. Проверьте пути к файлам в Execute Command нодах
7. Активируйте workflow

**Преимущества:**
- ✅ Все ноды правильно соединены
- ✅ Простая и стабильная архитектура
- ✅ Парсит все 3 платформы одной командой
- ✅ Легко отлаживать
- ✅ Готов к работе после импорта

## 🗄️ База данных

Используется SQLite с тремя таблицами:

### `rental_listings`
Хранит объявления об аренде:
- `id` - Уникальный ID
- `platform` - Платформа (cian/yandex/avito)
- `listing_id` - ID объявления на платформе
- `url` - Ссылка на объявление
- `phone` - Номер телефона
- `title`, `address`, `price`, `rooms`, `area`, `floor`, etc.
- `sent_to_manager` - Флаг отправки менеджеру
- `sent_at` - Время отправки
- `manager_id` - ID менеджера, получившего объявление

### `parsing_sessions`
Отслеживание сессий парсинга:
- `platform` - Платформа
- `started_at`, `completed_at`
- `listings_found`, `listings_new`
- `status` - Статус (running/completed/failed)

### `managers`
Менеджеры, получающие объявления:
- `telegram_id` - Telegram ID
- `name` - Имя
- `is_active` - Активен ли
- Фильтры: `city`, `max_price`, `min_rooms`

## 🔄 Логика работы

1. **Парсинг** (каждые 4 часа или по команде):
   - Запускаются парсеры для всех платформ
   - Данные собираются с учетом rate limiting
   - Новые объявления сохраняются в БД

2. **Извлечение телефонов**:
   - Для объявлений без телефонов
   - Открывается страница объявления
   - Извлекается номер телефона

3. **Отправка менеджеру**:
   - Выбираются неотправленные объявления
   - Форматируется сообщение
   - Отправляется в Telegram
   - Помечается маркером `sent_to_manager=True`

4. **Автодозвон** (опционально):
   - При наличии телефона отправляется webhook
   - Система телефонии инициирует звонок

## 🛡️ Защита от банов

### Прокси-серверы
- Ротация прокси для каждого запроса
- Автоматическое исключение неработающих прокси
- Поддержка HTTP/HTTPS/SOCKS5

### Rate Limiting
- Задержки 2-8 секунд между запросами
- Разные настройки для каждой платформы:
  - Cian: 3-6 сек
  - Yandex: 4-7 сек
  - Avito: 5-8 сек (самая строгая)

### User-Agent Rotation
- 8 различных User-Agent
- Случайный выбор для каждого запроса

### Рекомендации
- Используйте прокси для production
- Не парсьте слишком часто (рекомендуется 4-6 часов)
- Ограничивайте количество страниц (5-10 максимум)

## 📞 Интеграция автодозвона

Для работы автодозвона нужна интеграция с телефонией:

### Варианты:
1. **Asterisk** (открытая IP-телефония)
2. **Twilio** (облачная телефония)
3. **API мобильного устройства**
4. **Zadarma**, **Mango Office** (российские сервисы)

### Настройка:
1. Создайте webhook endpoint в вашем сервисе телефонии
2. Укажите URL в `.env`:
   ```
   AUTO_DIAL_WEBHOOK_URL=https://your-telephony.com/webhook
   ```
3. Webhook получит JSON:
   ```json
   {
     "phone": "+79991234567",
     "listing_id": "cian_abc123",
     "platform": "cian"
   }
   ```

## 🔧 Расширенное использование

### CLI аргументы

```bash
# Парсинг с настройками
python main.py \
  --city москва \
  --max-pages 10 \
  --platforms cian yandex \
  --db-path /path/to/db.sqlite \
  --proxy-file proxies.txt

python main.py --extract-phones --phone-limit 50

# Статистика
python main.py --stats
```

### Программное использование

```python
from parsers import CianParser, YandexRealtyParser
from utils.proxy_manager import ProxyManager, RequestSession

# Инициализация
proxy_manager = ProxyManager(['http://proxy1.com:8080'])
session = RequestSession(proxy_manager)

# Парсинг Cian
cian = CianParser(city='москва', request_session=session)
listings = cian.parse(max_pages=3)

# Извлечение телефона
phone = cian.extract_phone(listings[0]['url'])
```

## 🐛 Устранение проблем

### Ошибка "No proxy available"
- Проверьте формат прокси в `proxies.txt`
- Убедитесь, что прокси работают

### Парсер не находит объявления
- Сайты могли изменить структуру HTML
- Проверьте логи на ошибки
- Возможно, вас забанили (используйте прокси)

### Telegram бот не отвечает
- Проверьте `TELEGRAM_BOT_TOKEN`
- Убедитесь, что бот запущен: `python bot/telegram_bot.py`

### Не извлекаются телефоны
- Многие сайты скрывают телефоны за кнопкой "Показать"
- Требуется авторизация или решение CAPTCHA
- Для Avito особенно сложно извлечь телефон
