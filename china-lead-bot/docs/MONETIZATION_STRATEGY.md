## 💸 ДОПОЛНИТЕЛЬНЫЕ ИСТОЧНИКИ ДОХОДА

### 1. Pay-Per-Lead (PPL)

**Модель:** Оплата за результат

```
📌 Холодный лид (только данные): 100₽
📌 С email/телефоном: 200₽
📌 Квалифицированный (AI Score 7+): 300₽
📌 Теплый лид (ответил на запрос): 500₽
📌 Встреча назначена: 2,000₽
```

**Для кого:** Клиенты которые хотят платить за результат, а не абонплату

**Прогноз:**
```
50 клиентов × 20 лидов/мес × 300₽ = 300,000₽/мес
```

---

### 2. Комиссия от сделок

**Модель:** 1-3% от первой сделки с найденным поставщиком

**Механика:**
- Клиент находит поставщика через бота
- Делает заказ
- Отмечает в боте (/deal_closed $50,000)
- Мы получаем 1% = $500 = 50,000₽

**Для кого:** Крупные импортеры (проще платить % чем абонплату)

**Прогноз:**
```
10 клиентов × 2 сделки/мес × $30,000 × 1% = $6,000/мес
= ~600,000₽/мес 💰
```

---

### 3. Email Outreach Service

**Модель:** Платная услуга автоматической рассылки

**Тарифы:**
```
Starter: 1,990₽/мес - 500 emails
Growth: 4,990₽/мес - 2,000 emails
Scale: 9,990₽/мес - 10,000 emails
```

**Что включено:**
- AI-генерация персонализированных писем
- Автоматические follow-ups (3-5-7 дней)
- Tracking откликов
- A/B тестирование
- Warm-up email аккаунтов

**Для кого:** PRO и ENTERPRISE клиенты

**Прогноз:**
```
30 клиентов × среднее 5,000₽ = 150,000₽/мес
```

---


4. Получить первые платные клиенты

**Метрики:**
- 5+ положительных отзывов
- 3+ платных клиента
- NPS > 50

**SEO:**

**Партнерки:**

- Комиссия: 20%

**Метрики:**
- 100+ платных клиентов
