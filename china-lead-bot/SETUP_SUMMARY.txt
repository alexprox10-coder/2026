✅ ВСЁ ГОТОВО К НАСТРОЙКЕ!

Я настроил все необходимые файлы. Вам осталось только:

================================================================================
ШАГ 1: Получите Telegram Bot Token
================================================================================

1. Откройте Telegram
2. Найдите @BotFather
3. Отправьте: /newbot
4. Следуйте инструкциям
5. СКОПИРУЙТЕ ТОКЕН (формат: 1234567890:ABCdefGH...)

================================================================================
ШАГ 2: Получите n8n Webhook URL
================================================================================

1. Откройте n8n (http://localhost:5678 или app.n8n.cloud)
2. Импортируйте файл:
   china-lead-bot/workflows/chinaleadbot_workflow_v3.json
3. Настройте OpenAI credential
4. АКТИВИРУЙТЕ workflow (переключатель Active вверху)
5. Кликните узел "Webhook Trigger"
6. СКОПИРУЙТЕ "Production URL"

================================================================================
ШАГ 3: Запустите Quick Setup
================================================================================

cd /home/user/2026/china-lead-bot
./quick_setup.sh

Скрипт спросит:
- Telegram Bot Token (из шага 1)
- n8n Webhook URL (из шага 2)
- Google Sheets ID (опционально, нажмите Enter для пропуска)
- Anthropic API Key (опционально, нажмите Enter для пропуска)

================================================================================
ШАГ 4: Запустите бота
================================================================================

source venv/bin/activate
python bot/main.py

Вы увидите:
  INFO - Bot started successfully
  INFO - Username: @your_bot_name
  INFO - Bot is running...

================================================================================
ШАГ 5: Тестируйте!
================================================================================

1. Откройте Telegram
2. Найдите вашего бота
3. Отправьте /start
4. Нажмите "🔍 Найти поставщиков"
5. Следуйте инструкциям
6. Получите результаты! 🎉

================================================================================
АЛЬТЕРНАТИВА: Ручная настройка
================================================================================

Если quick_setup.sh не работает:

1. Откройте файл .env (уже создан):
   nano .env

2. Замените две строки:
   TELEGRAM_BOT_TOKEN=ваш_токен_от_botfather
   N8N_WEBHOOK_URL=ваш_webhook_url_из_n8n

3. Сохраните: Ctrl+O, Enter, Ctrl+X

4. Проверьте конфигурацию:
   python check_config.py

5. Установите зависимости:
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt

6. Запустите:
   python bot/main.py

TROUBLESHOOTING
================================================================================

Бот не запускается?
→ python check_config.py

Ошибка при поиске?
→ Проверьте что workflow Active в n8n
→ Проверьте баланс OpenAI

Timeout?
→ В bot/main.py строка 315 измените timeout=120 на timeout=300

Полный список решений: docs/TELEGRAM_BOT_SETUP.md (раздел Troubleshooting)
