## 🐛 TROUBLESHOOTING

### Ошибка: "chat not found"

**НЕ ДОЛЖНО БЫТЬ!** Но если появилась:

1. Откройте узел "Format Table"
2. Проверьте что в коде есть:
   ```javascript
   const chatId = firstItem.chat_id;

   if (!chatId) {
     throw new Error('chat_id отсутствует!');
   }

   return {
     json: {
       chat_id: chatId,  // ← ВАЖНО!
       message: message
     }
   };
   ```

3. Если этого нет - скопируйте код из workflow заново!

---

### Ошибка: "Authorization failed"

**Причина:** Неправильный OpenRouter API key

**Решение:**
1. Откройте узел "AI Analyze"
2. Headers → Authorization
3. Вставьте правильный ключ: `Bearer sk-or-v1-...`

---

### В сообщении "undefined"

**Причина:** Узел "Parse AI Response" не объединяет данные

**Решение:** Проверьте что в коде есть:
```javascript
const allSuppliers = $node["Generate Suppliers"].json;
const companyData = allSuppliers[index];

return {
  json: {
    ...companyData,  // Все данные компании
    ...aiData        // + AI анализ
  }
};
```
