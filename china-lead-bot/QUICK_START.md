5. **СОХРАНИТЕ ТОКЕН!** Он выглядит так:

Отправьте @BotFather команду `/setcommands`:


4. Создайте API Key → **СОХРАНИТЕ**

## ⚙️ ЭТАП 2: УСТАНОВКА (20 минут)

### Шаг 2.1: Клонируйте проект

```bash
cd /home/user/2026/china-lead-bot
```

### Шаг 2.2: Установите Python зависимости

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### Шаг 2.3: Создайте .env файл

```bash
cp .env.example .env
nano .env
```

**Минимальная конфигурация для старта:**

```bash
# Telegram
TELEGRAM_BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER

# Claude
ANTHROPIC_API_KEY=ВАШ_CLAUDE_API_KEY

# n8n (пока оставьте так)
N8N_WEBHOOK_URL=http://localhost:5678/webhook/lead-search

# Google Sheets (создадим позже)
GOOGLE_SHEET_ID=

# Остальное можно не трогать
```

Сохраните: `Ctrl+O` → `Enter` → `Ctrl+X`

### Шаг 2.4: Запустите n8n

**Простой способ (Docker):**

```bash
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n
```

Откройте браузер: http://localhost:5678

**Без Docker:**

```bash
npm install -g n8n
n8n start
```

### Шаг 2.5: Импортируйте workflow

1. В n8n → **Add workflow** → **Import from File**
2. Выберите `workflows/lead_generation.json`
3. Workflow загружен!

### Шаг 2.6: Настройте credentials

**Claude API:**
1. Credentials → Add Credential → "Anthropic API"
2. Paste API Key
3. Save

**Google Sheets (быстрый способ):**
1. Создайте таблицу: https://sheets.google.com
2. Скопируйте ID из URL
3. В .env → `GOOGLE_SHEET_ID=ВАШ_ID`
4. В n8n пропустите пока (можно настроить позже)

### Шаг 2.7: Активируйте workflow

В n8n:
1. Откройте workflow
2. Toggle переключатель **Active** вверху
3. Workflow работает! ✅

## 🆘 TROUBLESHOOTING

**Бот не отвечает:**
```bash
# Проверьте процесс
ps aux | grep python

# Перезапустите
cd bot
python main.py
```

**n8n не работает:**
```bash
# Проверьте что запущен
docker ps

# Перезапустите
docker restart n8n
```

**Claude API ошибка:**
- Проверьте баланс: https://console.anthropic.com
- Проверьте API key в .env
- Пополните счет

**Нет клиентов:**
- Увеличьте outreach (100+ сообщений/день)
- Улучшите предложение (add value)
- Дайте больше бесплатно
