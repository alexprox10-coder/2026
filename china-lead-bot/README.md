# 🇨🇳🇷🇺 ChinaLeadBot - AI Lead Generation Agent

**Автоматический поиск китайских поставщиков для российских импортеров**

## 🎯 Что делает бот

ChinaLeadBot - это AI-агент, который автоматизирует поиск и квалификацию китайских поставщиков:

- 🔍 **Поиск поставщиков** на Alibaba, 1688.com, Made-in-China
- 🎯 **Фильтрация** по категориям, MOQ, цене, рейтингу
- 📧 **Персонализированные запросы** на русском и китайском языках
- 💼 **Квалификация** лидов (проверка сертификатов, отзывов)
- 📊 **CRM интеграция** - экспорт в Google Sheets/Airtable
- 🤖 **AI анализ** компаний с помощью Claude

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd china-lead-bot
pip install -r requirements.txt
```

### 2. Настройка окружения

Скопируйте `.env.example` в `.env` и заполните:

```bash
cp .env.example .env
nano .env
```

Необходимые переменные:
- `TELEGRAM_BOT_TOKEN` - токен бота от @BotFather
- `ANTHROPIC_API_KEY` - API ключ Claude
- `N8N_WEBHOOK_URL` - URL webhook n8n
- `GOOGLE_SHEET_ID` - ID Google таблицы для лидов

### 3. Импорт n8n workflow

1. Откройте n8n
2. Import workflow из файла `workflows/lead_generation.json`
3. Настройте credentials (Claude API, Google Sheets)
4. Активируйте workflow

### 4. Запуск бота

```bash
cd bot
python main.py
```

## 📋 Команды бота

- `/start` - Начать работу, регистрация
- `/find <категория>` - Найти поставщиков
- `/settings` - Настройки поиска (MOQ, цена, регион)
- `/status` - Статус текущих поисков
- `/leads` - Показать найденные лиды
- `/export` - Экспорт в Google Sheets
- `/subscribe` - Управление подпиской
