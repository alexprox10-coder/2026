# 🎯 Система сбора лидов ПО ЗАПРОСУ

## Проблема старого подхода:
❌ Workflows работали автоматически по таймеру
❌ Нет контроля над процессом
❌ Нельзя запустить, когда нужно

## ✅ Новый подход:
✅ Все работает **ПО ВАШЕМУ ЗАПРОСУ**
✅ Полный контроль над каждым этапом
✅ Запускаете когда нужно через API

## 🔄 ПОЛНЫЙ ЦИКЛ РАБОТЫ (ВСЕ ПО ЗАПРОСУ!)

### Этап 1: Поиск компаний и их сайтов 🔍

**Workflow:** `child_workflow_01_AgentLeadAddQuery_FIXED.json`

**Вы отправляете запрос:**
```bash
curl -X POST https://your-n8n.com/webhook/add-search-query \
  -H "Content-Type: application/json" \
  -d '{
    "query": "агентство недвижимости",
    "city": "Благовещенск",
    "region": "Амурская область"
  }'
```

**Что происходит:**
1. Система ищет в Google (через SerpAPI)
2. Находит сайты компаний
3. Фильтрует (убирает соцсети, доски объявлений)
4. Добавляет в CompanySites (Status=0)

**Результат:**
```json
{
  "success": true,
  "websites_found": 15,
  "message": "Search completed"
}
```

---

### Этап 2: Сбор контактных данных с сайтов 📞

**Workflow:** `child_workflow_03_AgentLeadScrapInformationCompany_FIXED_v2.json`

**ПО ВАШЕМУ ЗАПРОСУ** (а не автоматически!):
```bash
curl -X POST https://your-n8n.com/webhook/start-scraping \
  -H "Content-Type: application/json" \
  -d '{}'
```

**Что происходит:**
1. Находит сайты со Status=0 (до 20 штук)
2. Загружает HTML каждого сайта
3. AI (Google Gemini) извлекает данные:
   - Название компании
   - ИНН
   - Адрес
   - Телефон
   - Email
   - Описание деятельности
   - Товары/услуги
   - Контактное лицо
4. Сохраняет в CompanyInformation
5. Обновляет Status → 2 (успех) или 3 (ошибка)

**Результат:**
```json
{
  "success": true,
  "companies_processed": 15,
  "message": "Scraping completed"
}
```

---

### Этап 3: Генерация персональных предложений ✉️

**Workflow:** `child_workflow_04_AgentLeadMailGenerate.json` 🆕

**ПО ВАШЕМУ ЗАПРОСУ**:
```bash
curl -X POST https://your-n8n.com/webhook/generate-proposals \
  -H "Content-Type: application/json" \
  -d '{}'
```

**Что происходит:**
1. Читает все компании из CompanyInformation
2. Фильтрует только те, у кого есть email
3. Для каждой компании AI генерирует:
   - **Персональную тему письма**
   - **Уникальный текст предложения**
   - Учитывает специфику их бизнеса
   - Подчеркивает конкретные выгоды
4. Сохраняет черновики в лист "EmailDrafts"

**Результат:**
```json
{
  "success": true,
  "emails_generated": 12,
  "message": "Proposals generated successfully"
}
```

## 📊 СТРУКТУРА GOOGLE SHEETS

### Лист 1: CompanySites
Сайты компаний для обработки

| ID | URL | Company Name | Status | Created At | Updated At | Source |
|----|-----|--------------|--------|------------|------------|--------|
| 1 | https://company1.ru | Компания 1 | 0 | 2026-01-14... | 2026-01-14... | google_search |

**Статусы:**
- 0 = новый (ждет обработки)
- 1 = в процессе
- 2 = данные собраны
- 3 = ошибка

### Лист 2: CompanyInformation
Собранные контактные данные

| ID | Site ID | Company Name | INN | Address | Phone | Email | Description | Products/Services | Contact Person | Scraped At |
|----|---------|--------------|-----|---------|-------|-------|-------------|-------------------|----------------|------------|
| 1 | 1 | Компания 1 | 123... | г. Благовещенск... | +7... | info@... | Описание | Услуги | Иванов И.И. | 2026-01-14... |

### Лист 3: EmailDrafts 🆕
Персональные предложения (черновики)

| ID | Site ID | Company Name | Email | Subject | Body | Generated At | Status |
|----|---------|--------------|-------|---------|------|--------------|--------|
| 1 | 1 | Компания 1 | info@... | Персональная тема | HTML текст письма | 2026-01-14... | draft |

**Статусы:**
- draft = черновик (не отправлено)
- sent = отправлено
- failed = ошибка отправки

## 🚀 БЫСТРЫЙ СТАРТ

### Шаг 1: Подготовка Google Sheets

1. Создайте таблицу с 3 листами:
   - CompanySites
   - CompanyInformation
   - EmailDrafts (новый!)

2. Используйте готовые CSV шаблоны или создайте вручную

3. Скопируйте ID таблицы

### Шаг 2: Получите API ключи

**Google Gemini API** (БЕСПЛАТНО!):
```
https://aistudio.google.com/app/apikey
```

**SerpAPI** (100 запросов/месяц бесплатно):
```
https://serpapi.com/users/sign_up
```

### Шаг 3: Импортируйте workflows в n8n

```
✅ child_workflow_01_AgentLeadAddQuery_FIXED.json          (поиск сайтов)
✅ child_workflow_03_AgentLeadScrapInformationCompany_FIXED_v2.json (сбор данных) 🆕
✅ child_workflow_04_AgentLeadMailGenerate.json             (генерация писем) 🆕
```

### Шаг 4: Настройте credentials

1. **Google Gemini API:**
   - Settings → Credentials → Add
   - Выберите: Google Gemini API
   - Вставьте ключ

2. **SerpAPI:**
   - Settings → Credentials → Add
   - Выберите: HTTP Query Auth
   - Name: `api_key`
   - Value: ваш ключ

3. **Google Sheets OAuth2:**
   - Авторизуйтесь через Google

### Шаг 5: Замените Google Sheet ID

Во всех 4 workflows замените:
```
YOUR_GOOGLE_SHEET_ID_HERE → ваш реальный ID
```

### Шаг 6: Активируйте workflows

В каждом workflow нажмите **"Active"**

## 🔧 ЧАСТЫЕ ВОПРОСЫ

### Q: Можно ли запускать автоматически по расписанию?
**A:** Да! Вместо webhook триггера используйте Schedule Trigger. Но **по запросу гибче** - вы контролируете процесс.

### Q: Нужно ли платить за Google Gemini?
**A:** Нет! Бесплатный лимит достаточен для небольших объемов. Для серьезных объемов - ~$5-10 за 1000 компаний.

### Q: Как часто запускать сбор данных?
**A:** Как захотите! Рекомендую:
- Поиск: 1 раз в неделю
- Сбор данных: сразу после поиска
- Генерация писем: когда накопится 20-30 компаний

### Q: Можно ли редактировать письма перед отправкой?
**A:** Да! Все черновики сохраняются в EmailDrafts. Откройте Google Sheets и отредактируйте.

### Q: Как отправить письма?
**A:** Два способа:
1. Вручную - скопируйте текст из EmailDrafts и отправьте
2. Автоматически - создайте еще один workflow для отправки (можем добавить!)
