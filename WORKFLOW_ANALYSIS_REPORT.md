## 🔄 КАК РАБОТАЕТ WORKFLOW (Основные циклы)

### Цикл 1: Генерация запросов (строки 15-273)

```
Триггер → Perplexity AI → Разбор ответа → Разделение на элементы
    ↓
Удаление дубликатов → Проверка в Google Sheets → Добавление новых запросов
```

**Что делает:**
- Получает город и тематику (например: "Хабаровск, недвижимость")
- Perplexity AI генерирует ВСЕ улицы города
- Создает запросы вида: "хабаровск+недвижимость+улица_ленина"
- Сохраняет в лист "Запросы" со статусом 0

### Цикл 2: Поиск компаний (строки 352-930)

```
Взять запросы (статус=0) → Поиск в Google Maps → Извлечь URL сайтов
    ↓
Фильтр (убрать blacklist) → Удалить дубликаты → Сохранить в "Компании"
```

**Что делает:**
- Берёт до 2 необработанных запросов
- Ищет в Google Maps
- Извлекает сайты компаний
- Фильтрует (убирает social media, avito и т.д.)
- Сохраняет в лист "Компании"
- Обновляет статус запроса на 1

### Цикл 3: Сбор информации (строки 1568-2348)

```
Взять компании (статус данных=0) → Загрузить HTML сайта → Парсинг
    ↓
Извлечь email/телефон (regex) → AI анализ компании → Обновить Google Sheets
```

**Что делает:**
- Берёт до 10 компаний без данных
- Загружает HTML сайта
- Regex ищет email и телефоны
- AI (Claude) анализирует чем занимается компания
- Сохраняет всё в Google Sheets
- Обновляет статус данных на 1

### Цикл 4: Генерация писем КП (строки 1296-1724)

```
Взять компании (черновик=0) → AI генерация письма → Сохранить черновик
```

**Что делает:**
- Берёт до 20 компаний с email но без черновика письма
- AI (Claude через OpenRouter) создаёт персональное КП
- Сохраняет HTML письмо в столбец "Черновик письма"

### Telegram AI Agent (строки 1088-1379)

```
Telegram → Транскрипция голоса (если нужно) → AI Agent
    ↓
AI Agent вызывает инструменты:
  - AgentLeadAddQuery (добавить запросы)
  - AgentLeadAddSiteCompany (добавить сайты)
  - AgentLeadScrapInformationCompany (собрать инфо)
  - AgentLeadMailGenerate (создать письма)
  - QuerySheets / SiteCompanySheets (прочитать данные)
  - TelegramMessage (отправить сообщение)
    ↓
Результат → Telegram
```

**Что делает:**
- Принимает сообщения от пользователя (текст или голос)
- OpenAI Whisper транскрибирует голосовые
- AI Agent (Claude через OpenRouter) понимает команду
- Вызывает нужные workflow-инструменты
- Возвращает результат в Telegram

## ⚠️ ПРОБЛЕМЫ И РИСКИ

### Высокий приоритет:

1. **Отсутствие дочерних workflows** → AI Agent не работает
2. **Открытый API ключ Perplexity** → Риск кражи и списания средств
3. **Workflow не активен** → Ничего не работает
4. **Credential Google Sheets может истечь** → OAuth токены надо обновлять

### Средний приоритет:

1. **Устаревшая модель Claude** → `claude-3.7-sonnet` может быть deprecated
2. **Webhook IDs могут быть stale** → Wait узлы могут не работать
3. **Опечатка в названии столбца** → "Рабор" вместо "Разбор"
4. **Нет обработки ошибок** → Если API упадёт, workflow остановится

### Низкий приоритет:

1. **Жёсткие лимиты** → Max 2 запроса, 10 компаний, 20 писем за раз
2. **Blacklist доменов может быть неполным** → Могут попасть нерелевантные сайты
3. **Regex для email/телефонов может пропускать** → Нестандартные форматы
