# 🔍 Отладка изображений Авито

## Проблема

ЦИАН приходит с фото, а Авито без фото.

## Что сделано

Добавлена отладочная информация в узел **"Обработка Авито"**, которая сохраняется в Google Sheets в поле `debug_imageFields`.

---

## Как проверить, какие поля возвращает Avito

### Шаг 1: Запустите парсинг Авито

1. В Telegram нажмите кнопку **"🏢 Авито"**
2. Дождитесь завершения парсинга (~2-3 минуты)

### Шаг 2: Откройте Google Sheets

Откройте вашу таблицу:
https://docs.google.com/spreadsheets/d/1IptmHSeKMRMAWB8QzYfyj1vjSJ2Pa0ZdrMq--fMuCW8/edit

### Шаг 3: Найдите колонку debug_imageFields

В таблице будет колонка **`debug_imageFields`** со значением вроде:

```json
{
  "image": "exists",
  "imageUrl": "missing",
  "images": "array[5]",
  "photos": "missing",
  "img": "missing",
  "photo": "missing",
  "thumbnail": "exists"
}
```

Это покажет, какие поля **присутствуют** в данных от Avito.

---

## Возможные варианты

### Вариант 1: Поля существуют, но формат неправильный

Если видите `"images": "array[5]"` или `"image": "exists"`, значит поле есть, но формат данных не тот, что мы ожидаем.

**Решение:** Нужно посмотреть реальную структуру данных в n8n:
1. Откройте n8n
2. Выполните workflow вручную
3. Кликните на узел **"Результаты Авито"**
4. Посмотрите вывод - там будет JSON с реальными данными
5. Найдите поле с изображением и его формат

### Вариант 2: Все поля "missing"

Если все поля `"missing"`, значит Avito actor вообще не возвращает изображения.

**Решение:**
- Проверьте настройки Apify actor
- Возможно, нужно включить опцию для загрузки изображений
- Или использовать другой Avito actor

### Вариант 3: Поле есть, но не URL

Если `"image": "exists"`, но это не строка с `http`, возможно это:
- Относительный путь (нужно добавить префикс)
- ID изображения (нужно построить URL)
- Закодированные данные (base64)

---

## Улучшенный код обработки

Код теперь проверяет:

1. **Строковые поля с URL:**
   - `data.image`
   - `data.imageUrl`
   - `data.img`
   - `data.photo`
   - `data.thumbnail`

2. **Массивы:**
   - `data.images[]` - массив строк или объектов
   - `data.photos[]` - массив строк или объектов

3. **Объекты в массивах:**
   - `images[0].url`
   - `images[0].src`
   - `images[0].href`
   - `images[0].link`

4. **Валидация:**
   - Проверка типа `typeof === 'string'`
   - Проверка что начинается с `http`
