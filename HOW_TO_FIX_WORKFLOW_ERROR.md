# 🛠️ Как исправить ошибку "Workflow does not exist"

## 🎯 Краткое резюме проблемы

Ваш Telegram бот с AI Agent **НЕ МОЖЕТ РАБОТАТЬ**, потому что:

❌ Отсутствуют **4 дочерних workflow**
❌ Главный workflow **НЕ АКТИВИРОВАН**
❌ API ключ Perplexity **ОТКРЫТ ПУБЛИЧНО** (риск кражи!)

---

## ⚡ БЫСТРОЕ РЕШЕНИЕ (5 минут)

Если нужно быстро запустить:

### Шаг 1: Проверьте дочерние workflows

1. Откройте n8n
2. Перейдите в **Workflows**
3. Найдите эти 4 workflow:

   - `AgentLeadAddQuery`
   - `AgentLeadAddSiteCompany`
   - `AgentLeadScrapInformationCompany`
   - `AgentLeadMailGenerate`

4. Если они есть → **активируйте их** (Active: ON)
5. Если их нет → **создайте** (см. "Полное решение" ниже)

### Шаг 2: Активируйте главный workflow

1. Откройте workflow **"АГЕНТ ЛИДЫ+КП 2026_v2.0"**
2. В правом верхнем углу переключите **Active: ON**
3. Проверьте что нет ошибок

### Шаг 3: Тест

Напишите в Telegram бота:
```
Привет! Проверка связи
```

Должен ответить AI Agent.

## 🔧 ПОЛНОЕ РЕШЕНИЕ (Пошагово)

### ЧАСТЬ 1: Безопасность (КРИТИЧНО!)

#### 1.1 Отзовите скомпрометированный API ключ

Ваш API ключ Perplexity виден публично в GitHub issue!

1. Перейдите на https://www.perplexity.ai/settings/api
2. Войдите в аккаунт
3. Найдите ключ начинающийся с `pplx-jyeezdSQ...`
4. Нажмите **"Revoke"** или **"Delete"**

#### 1.2 Создайте новый API ключ

1. На той же странице нажмите **"Create New API Key"**
2. Дайте название: `n8n Workflow 2026`
3. Скопируйте ключ (он покажется один раз!)

#### 1.3 Сохраните в n8n credentials

1. В n8n: **Settings → Credentials**
2. Нажмите **"Add Credential"**
3. Найдите **"HTTP Header Auth"** или **"Header Auth"**
4. Заполните:
   ```
   Name: Perplexity AI API
   Header Name: Authorization
   Header Value: Bearer ВАШ_НОВЫЙ_КЛЮЧ
   ```
5. Нажмите **"Save"**

#### 1.4 Обновите workflow

1. Откройте **"АГЕНТ ЛИДЫ+КП 2026_v2.0"**
2. Найдите узел **"HTTP Request"** (самый первый после триггера)
3. Кликните на него
4. В разделе **"Authentication"**:
   - Выберите **"Predefined Credential Type"**
   - Выберите **"Header Auth"**
   - Выберите созданный credential **"Perplexity AI API"**
5. Удалите старый хардкод из **"Header Parameters"**
6. Нажмите **"Save"** workflow

### ЧАСТЬ 2: Создание недостающих workflows

Вам нужно создать **4 дочерних workflow**. Каждый должен иметь **точный ID** чтобы AI Agent мог их найти.

#### 2.1 Как создать workflow с конкретным ID

**ПРОБЛЕМА:** n8n автоматически генерирует ID, нельзя задать вручную через UI.

2. Нажмите **"Import from File"**
3. Выберите файл `child_workflow_01_AgentLeadAddQuery.json` (из этого репозитория)
4. Проверьте настройки:
   - Google Sheets ID: `1c5uhlu79eVVGc_YWR1Af4a67w2JyrEVwSYzkGXG4nGA`
   - Лист: "Запросы"
   - Credential: `hcA6b5dWS2JjEtNT`
5. **Активируйте workflow** (Active: ON)

#### 2.3 Workflow #2: AgentLeadAddSiteCompany

**Что делает:** Добавляет сайты компаний в Google Sheets

**Как создать:**

3. Выберите файл `child_workflow_02_AgentLeadAddSiteCompany.json`

#### 3.1 Проверьте доступ к таблице

1. Откройте https://docs.google.com/spreadsheets/d/1c5uhlu79eVVGc_YWR1Af4a67w2JyrEVwSYzkGXG4nGA/edit

⚠️ **ВАЖНО:** Опечатка "Рабор" должна быть ИМЕННО так! Не исправляйте!

1. В n8n: **Settings → Credentials**
2. Найдите credential с ID `hcA6b5dWS2JjEtNT`

4. Если его нет или он не работает:
   - Создайте новый **Google Sheets OAuth2** credential

   - Обновите ID во всех workflow

## 🔍 ДИАГНОСТИКА ПРОБЛЕМ

### Ошибка: "Workflow does not exist"

**Причина 1:** Дочерний workflow не существует
- **Решение:** Создайте недостающий workflow с правильным ID

**Причина 2:** Дочерний workflow не активен
- **Решение:** Активируйте его (Active: ON)

**Причина 3:** ID workflow не совпадает
- **Решение:** Проверьте ID в главном workflow и в дочернем

### Ошибка: "Missing credentials"

**Причина:** Credential не настроен или удалён
- **Решение:** Создайте или обновите credential в Settings

### Ошибка: "Invalid API key"

**Причина:** API ключ неверный или отозван
- **Решение:** Обновите API ключ в credentials

### Ошибка: "Cannot find column"

**Причина:** Названия столбцов в Google Sheets не совпадают
- **Решение:** Проверьте точное написание столбцов (включая опечатки!)

### Бот не отвечает в Telegram

**Причина 1:** Webhook не зарегистрирован
- **Решение:** Деактивируйте и снова активируйте workflow

**Причина 2:** Telegram credential неверный
- **Решение:** Проверьте token бота

**Причина 3:** Workflow не активен
- **Решение:** Активируйте (Active: ON)

## 🎓 ДОПОЛНИТЕЛЬНЫЕ РЕКОМЕНДАЦИИ

### Мониторинг расходов на API

Этот workflow использует платные API:

| API | Примерная стоимость | Когда списывается |
|-----|---------------------|-------------------|
| Perplexity AI | $0.005-0.02 за запрос | При генерации списка улиц |
| OpenRouter (Claude) | $0.015 за 1K tokens | AI Agent, анализ компаний, письма |
| OpenAI (Whisper) | $0.006 за минуту | Голосовые сообщения в Telegram |

**Рекомендация:** Установите лимиты на количество обработок:
- Узлы Limit ограничивают за раз: 2 запроса, 10 компаний, 20 писем
- Можете уменьшить если расходы высоки

### Резервное копирование

**Google Sheets - это ваша база данных!**

Рекомендую:
1. Включить историю версий в Google Sheets
2. Периодически экспортировать в CSV
3. Настроить автобэкап через Google Apps Script

### Масштабирование

Если обрабатываете много запросов:

1. **Увеличьте лимиты** в узлах Limit
2. **Добавьте паузы** (Wait nodes) чтобы не упереться в rate limits
3. **Мониторьте Google Sheets quota** (читаете/пишете много - можете упереться в лимит)
