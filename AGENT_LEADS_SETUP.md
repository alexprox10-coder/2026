# 🏢 Настройка workflow "AgentLeadAddQuery" - Пошаговая инструкция

## ⚠️ Проблема которую решаем

**Ошибка:** `"Workflow does not exist"` (Рабочий процесс не существует)

**Причина:** Workflow существует в n8n, но либо:
- ❌ Не активирован
- ❌ Неправильно настроены credentials (учетные данные)
- ❌ Отсутствуют необходимые подключения
- ❌ Webhook URL не совпадает с тем, что используется в вызовах

---

## 🔧 Шаг 1: Войдите в n8n и найдите workflow

1. **Откройте панель n8n** в браузере
   - URL обычно: `http://localhost:5678` или `https://ваш-домен.com`

2. **Перейдите в раздел Workflows**
   - Кликните на **"Workflows"** в боковом меню

3. **Найдите workflow AgentLeadAddQuery**
   - Поищите workflow с названием содержащим:
     - `AgentLeadAddQuery`
     - `Агентства недвижимости`
     - `Lead Query`
     - Или похожее название

4. **Откройте workflow**
   - Кликните на него для редактирования

---

## 🔍 Шаг 2: Проверьте структуру workflow

Убедитесь что workflow содержит следующие узлы:

### Обязательные узлы:

✅ **Webhook Trigger** (📥 Триггер для принятия запросов)
- Тип: `n8n-nodes-base.webhook`
- Должен быть настроен на принятие POST или GET запросов

✅ **AI Agent или HTTP Request** (🤖 Для обработки запросов)
- Для поиска информации об агентствах

✅ **Response Node** (✅ Для возврата ответа)
- Тип: `n8n-nodes-base.respondToWebhook`
- Должен возвращать результат вызывающей системе

---

## ⚙️ Шаг 3: Настройка Webhook (КРИТИЧНО!)

### 3.1 Откройте узел Webhook

1. Кликните на узел **Webhook** в начале workflow
2. В настройках найдите секцию **"Webhook URLs"**

### 3.2 Проверьте URL webhook

Вы увидите два URL:

**Test URL** (тестовый):
```
https://ваш-домен.com/webhook-test/ваш-путь
```

**Production URL** (рабочий):
```
https://ваш-домен.com/webhook/ваш-путь
```

### 3.3 Настройте параметры

В настройках webhook установите:

```
HTTP Method: POST (или ALL если нужны разные методы)
Path: agent-lead-query (или ваш кастомный путь)
Authentication: None (или настройте по необходимости)
Response Mode: "Using Respond to Webhook Node"
```

### 3.4 ВАЖНО: Скопируйте Production URL

Это тот URL, который нужно использовать в вашей системе!

**Пример:**
```
https://n8n.example.com/webhook/agent-lead-query
```

## 🔐 Шаг 4: Проверьте Credentials (Учетные данные)

### 4.1 Anthropic API (если используется AI)

1. Найдите узел с **Anthropic Claude** или **OpenAI**
2. Кликните на него
3. Проверьте что credentials выбран:
   - Если видите **"Select Credential"** - нужно настроить!

**Как настроить Anthropic API:**
1. Кликните **"Create New Credential"**
2. Введите ваш **API Key** от Anthropic
   - Получить можно на: https://console.anthropic.com/
3. Сохраните

### 4.2 Google Sheets (если сохраняете результаты)

1. Найдите узел **Google Sheets**
2. Проверьте что credentials настроен
3. Укажите **ID вашей Google таблицы**

**Где найти ID таблицы:**
- Откройте таблицу в браузере
- URL будет: `https://docs.google.com/spreadsheets/d/ВАШ_ID_ЗДЕСЬ/edit`
- Скопируйте часть между `/d/` и `/edit`

## ✅ Шаг 5: Активация workflow

### 5.1 Проверьте что все узлы подключены

- Все узлы должны быть соединены стрелками
- Не должно быть красных ошибок

### 5.2 Активируйте workflow

1. В правом верхнем углу найдите переключатель **"Active"**
2. Переключите его в положение **ON** (включено)
3. Статус должен стать: **Active ✓**

### 5.3 Проверьте что активация прошла успешно

- Не должно появиться сообщений об ошибках
- Если появились - читайте ошибку и исправьте проблему

## 🧪 Шаг 6: Тестирование workflow

### 6.1 Тест через n8n интерфейс

1. В workflow кликните **"Test Workflow"** (кнопка вверху)
2. Кликните на узел **Webhook**
3. Нажмите **"Listen for Test Event"**
4. Используйте **Test URL** для отправки запроса

### 6.2 Тест через curl (командная строка)

Откройте терминал и выполните:

```bash
curl -X POST https://ваш-домен.com/webhook/agent-lead-query \
  -H "Content-Type: application/json" \
  -d '{
    "query": "агентства недвижимости",
    "city": "Хабаровск",
    "limit": 5
```

**Замените:**
- `https://ваш-домен.com/webhook/agent-lead-query` на ваш реальный Production URL
- Параметры `query`, `city`, `limit` на нужные вам

## 🔴 Шаг 7: Решение частых проблем

### Проблема 1: "Workflow does not exist"

**Причина:** Workflow не активен или webhook URL неправильный

**Решение:**
1. ✅ Активируйте workflow (переключатель Active: ON)
2. ✅ Проверьте что используете **Production URL**, а не Test URL
3. ✅ Проверьте что путь webhook совпадает с тем что в запросе

### Проблема 2: "Missing credentials"

**Причина:** Не настроены API ключи

**Решение:**
1. ✅ Настройте Anthropic API credentials
2. ✅ Настройте Google Sheets credentials (если используется)

### Проблема 3: "Invalid API key"

**Причина:** API ключ неправильный или истек

**Решение:**
1. ✅ Проверьте API ключ на https://console.anthropic.com/
2. ✅ Создайте новый ключ если нужно
3. ✅ Обновите credentials в n8n

### Проблема 4: "Timeout" или workflow не отвечает

**Причина:** Слишком долгая обработка

**Решение:**
1. ✅ Увеличьте timeout в настройках webhook
2. ✅ Проверьте что AI модель отвечает (может быть перегружена)
3. ✅ Уменьшите параметр `limit` в запросе

### Проблема 5: Workflow активен но не срабатывает

**Причина:** Webhook не слушает запросы

**Решение:**
1. ✅ Деактивируйте и снова активируйте workflow
2. ✅ Проверьте логи n8n (Settings → Executions)
3. ✅ Убедитесь что n8n доступен по сети

## 📞 Нужна помощь?

Если после выполнения всех шагов workflow всё равно не работает:

1. **Проверьте логи выполнения:**
   - В n8n: Settings → Executions
   - Найдите последние запуски workflow
   - Посмотрите на какой узел ошибка

2. **Проверьте статус n8n:**
   - Убедитесь что n8n запущен и доступен
   - Проверьте нет ли ошибок в консоли n8n

3. **Экспортируйте workflow:**
   - В n8n: нажмите "..." → "Download"
   - Сохраните JSON файл
   - Отправьте мне для анализа
