# 🔧 Исправление ошибки "too many requests" в n8n workflow

## Проблема

Ошибка: **"The service is receiving too many requests from you"**

**Причина:**
Узел "Google Sheets1" проверяет существование каждого запроса в Google таблице, что вызывает слишком много обращений к Google Sheets API → rate limiting.

**Где ошибка:**
- Узел: "Google Sheets1"
- Operation: Get Row(s)
- Положение в workflow: после "Loop Over Items"

---

## Решение №1: Удалить лишнюю проверку дубликатов (РЕКОМЕНДУЕТСЯ)

В workflow УЖЕ ЕСТЬ узел "Remove Duplicates" который убирает дубликаты в памяти! Узел "Google Sheets1" и "If" делают ту же проверку, но через Google API - это избыточно и вызывает rate limiting.

### Что делать в n8n:

1. **Откройте workflow** "АГЕНТ ЛИДЫ+КП 2026_v2.0"

2. **Удалите узел "Google Sheets1":**
   - Найдите узел "Google Sheets1" (он подключен к "Loop Over Items" → второй выход)
   - Нажмите на узел → Delete

3. **Удалите узел "If":**
   - Найдите узел "If" (он подключен после "Google Sheets1")
   - Нажмите на узел → Delete

4. **Переподключите поток:**
   - От "Loop Over Items" (второй выход) → напрямую к следующему узлу
   - Обычно это узел который создает финальное сообщение или заканчивает workflow

5. **Сохраните и активируйте workflow**

---

## Решение №2: Добавить задержку между запросами (если хотите сохранить проверку)

Если вы хотите ОБЯЗАТЕЛЬНО проверять дубликаты через Google Sheets:

### Что делать:

1. **Добавьте узел "Wait" ПЕРЕД "Google Sheets1":**
   - Drag & Drop → "Wait" node
   - Поставьте между "Loop Over Items" и "Google Sheets1"

2. **Настройте задержку:**
   ```
   Resume: After time interval
   Wait Amount: 2 секунды
   ```

3. **Увеличьте batch size в "Loop Over Items":**
   - Откройте узел "Loop Over Items"
   - Параметры → Options → Batch Size: 10
   - Это уменьшит количество запросов

---

## Решение №3: Прочитать ВСЕ запросы ОДИН раз

Более эффективное решение - прочитать все существующие запросы ДО цикла:

### Что делать:

1. **Переместите "Google Sheets1" ДО узла "Loop Over Items":**
   - Удалите фильтры (Filters) из "Google Sheets1"
   - Пусть читает ВСЕ запросы из таблицы

2. **Добавьте Code node для проверки дубликатов:**
   ```javascript
   // Получаем существующие запросы из Google Sheets
   const existingQueries = $('Google Sheets1').all().map(item => item.json['Запросы']);

   // Фильтруем новые запросы, убирая дубликаты
   const newQueries = [];
   for (const item of $input.all()) {
     const query = item.json.contentArray;
     if (!existingQueries.includes(query)) {
       newQueries.push(item);
     }
   }

   return newQueries;
   ```

3. **Подключите поток:**
   ```
   Split Out → Google Sheets1 (читает ВСЕ запросы)
         ↓
      Code (фильтрует дубликаты)
         ↓
   Loop Over Items → Google Sheets (добавляет только новые)
   ```

## Почему сайты не попадают в таблицу?

### Проверьте Cycle 2:

Если запросы не добавляются из-за rate limiting, то Cycle 2 (автоматический поиск сайтов) НЕ РАБОТАЕТ, потому что:
1. В листе "Запросы" нет записей со статусом 0
2. Cycle 2 ищет только запросы со статусом 0
3. Нет запросов → нет поиска → нет сайтов

### Тестирование:

**Тест 1: Добавить запрос вручную в Google Sheets**
1. Откройте таблицу "Лиды компаний"
2. Лист "Запросы"
3. Добавьте строку:
   - Запросы: `стоматология самара`
   - Статус выполнения: `0`

4. Подождите 10 минут (или запустите Cycle 2 вручную в n8n)

5. Проверьте лист "Компании" - должны появиться найденные сайты

**Тест 2: Проверить Cycle 2 активирован**
1. Откройте n8n
2. Найдите workflow "Цикл 2 - Поиск сайтов компаний"
3. Убедитесь что он **Active** (переключатель включен)
4. Проверьте API ключ Perplexity настроен

## Быстрое решение ПРЯМО СЕЙЧАС:

### Обойти проблему без изменения workflow:

1. **Добавьте запрос ВРУЧНУЮ в Google Sheets:**
   - Откройте таблицу
   - Лист "Запросы"
   - Добавьте: `риэлторские агентства хабаровск` | `0`

2. **Запустите Cycle 2 вручную:**
   - Откройте n8n
   - Workflow "Цикл 2 - Поиск сайтов компаний"
   - Execute Workflow

3. **Проверьте результат:**
   - Лист "Компании" должен заполниться найденными сайтами

## Рекомендация:

**Используйте Решение №1** - просто удалите узлы "Google Sheets1" и "If".
Они дублируют функционал узла "Remove Duplicates" и вызывают rate limiting.

Workflow будет работать так:
```
Code (генерация запросов)
  ↓
Remove Duplicates (убирает дубликаты в памяти)
  ↓
Split Out
  ↓
Loop Over Items
  ↓
Google Sheets (добавляет запросы)
```

Это проще, быстрее и НЕ вызывает rate limiting!
