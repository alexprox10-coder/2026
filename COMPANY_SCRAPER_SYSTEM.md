# Система сбора данных о компаниях

## Описание системы

Система автоматического сбора и обработки информации о компаниях Амурской области с их веб-сайтов.

## Архитектура

### Компоненты системы:

1. **База данных** (Google Sheets или PostgreSQL)
   - Хранение списка сайтов компаний
   - Статусы обработки
   - Собранная информация

2. **n8n Workflows**
   - `AgentLeadAddSiteCompany` - добавление новых сайтов в базу
   - `AgentLeadScrapInformationCompany` - сбор информации с сайтов

## Структура базы данных

### Таблица: CompanySites

| Поле | Тип | Описание |
|------|-----|----------|
| id | INT | Уникальный идентификатор |
| url | STRING | URL сайта компании |
| company_name | STRING | Название компании |
| status | INT | Статус обработки (0=новый, 1=в обработке, 2=обработан, 3=ошибка) |
| created_at | DATETIME | Дата добавления |
| updated_at | DATETIME | Дата последнего обновления |
| source | STRING | Источник добавления |

### Таблица: CompanyInformation

| Поле | Тип | Описание |
|------|-----|----------|
| id | INT | Уникальный идентификатор |
| site_id | INT | ID из таблицы CompanySites |
| company_name | STRING | Название компании |
| inn | STRING | ИНН |
| address | STRING | Адрес |
| phone | STRING | Телефон |
| email | STRING | Email |
| description | STRING | Описание деятельности |
| products_services | TEXT | Товары и услуги |
| contact_person | STRING | Контактное лицо |
| scraped_at | DATETIME | Дата сбора данных |
| raw_data | JSON | Сырые данные в формате JSON |

## Workflows

### 1. AgentLeadAddSiteCompany

**Назначение:** Добавление новых сайтов компаний в базу данных

**Триггеры:**
- HTTP Webhook (POST запрос с URL сайта)
- Расписание (импорт из внешних источников)
- Ручной запуск

**Логика работы:**
1. Получение URL сайта (через webhook или из источника)
2. Валидация URL
3. Проверка на дубликаты в базе
4. Добавление в таблицу CompanySites со статусом 0 (новый)
5. Возврат подтверждения

**Входные данные:**
```json
{
  "url": "https://example-company.ru",
  "company_name": "Название компании (опционально)",
  "source": "manual|import|api"
}
```

**Выходные данные:**
```json
{
  "success": true,
  "site_id": 123,
  "message": "Site added successfully"
}
```

### 2. AgentLeadScrapInformationCompany

**Назначение:** Сбор информации с сайтов компаний

**Триггеры:**
- Расписание (каждые 6 часов)
- Ручной запуск

**Логика работы:**
1. Получение списка сайтов со статусом 0 (новые)
2. Обновление статуса на 1 (в обработке)
3. Для каждого сайта:
   - Загрузка HTML страницы
   - Извлечение структурированных данных
   - Использование AI для анализа и извлечения информации
   - Сохранение в таблицу CompanyInformation
4. Обновление статуса на 2 (обработан) или 3 (ошибка)

**AI Промпт для извлечения данных:**
```
Проанализируй HTML-код сайта компании и извлеки следующую информацию:
- Название компании
- ИНН (если указан)
- Адрес
- Телефон(ы)
- Email
- Описание деятельности
- Основные товары/услуги
- Контактное лицо

Верни данные в формате JSON.
```

**Обработка ошибок:**
- Сайт недоступен → статус 3, повторная попытка через 24 часа
- Таймаут → статус 3, повторная попытка
- Нет данных → статус 2, пустые поля

## Необходимые credentials в n8n

1. **Google Sheets OAuth2**
   - Для чтения/записи данных в Google Sheets

2. **Anthropic API** (опционально, для AI-анализа)
   - Для интеллектуального извлечения данных

3. **HTTP Request** (опционально)
   - Для webhook endpoints

## Примеры использования

### Добавление сайта через webhook:

```bash
curl -X POST https://your-n8n-instance.com/webhook/add-company-site \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://amur-company.ru",
    "company_name": "Амурская компания",
    "source": "manual"
  }'
```

### Запуск сбора данных вручную:

1. Откройте n8n
2. Найдите workflow "AgentLeadScrapInformationCompany"
3. Нажмите "Execute Workflow"

## Мониторинг и отладка

### Проверка статистики:

- Сайтов в очереди (status=0): должно быть > 0 для работы сбора
- Сайтов в обработке (status=1): не должно быть > 10 одновременно
- Обработанных (status=2): растет при успешной работе
- С ошибками (status=3): требует ручной проверки

### Типичные проблемы:

1. **"Workflow does not exist"**
   - Проверьте, что workflow импортирован в n8n
   - Проверьте имя workflow (должно точно совпадать)

2. **"The workflow did not return a response"**
   - Увеличьте timeout для HTTP Request узлов
   - Проверьте логи выполнения в n8n
   - Проверьте доступность сайтов

3. **"Нет сайтов со статусом 0"**
   - Добавьте новые сайты через AgentLeadAddSiteCompany
   - Проверьте, что предыдущие запуски завершились успешно
   - Сбросьте статус на 0 для повторной обработки (если нужно)

## Масштабирование

Для обработки большого количества сайтов:

1. Добавьте паузы между запросами (3-5 секунд)
2. Обрабатывайте максимум 20 сайтов за один запуск
3. Используйте rate limiting для защиты от блокировок
4. Настройте User-Agent для имитации браузера

## Безопасность

1. Не храните пароли и API ключи в workflow
2. Используйте n8n credentials для всех API
3. Валидируйте все входящие URL
4. Используйте HTTPS для всех запросов
