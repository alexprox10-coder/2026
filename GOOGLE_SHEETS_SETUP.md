# 📊 Настройка Google Sheets для n8n workflows

## Быстрая настройка (5 минут)

### Шаг 1: Создать новую таблицу Google Sheets

1. Откройте Google Sheets: https://sheets.google.com
2. Создайте новую таблицу
3. Назовите её: **"Лиды компаний"**

### Шаг 2: Создать лист "Компании"

1. Переименуйте первый лист в **"Компании"**
2. Скопируйте эти заголовки в первую строку:

```
Сайт | Компания | Город | Запрос | Дата добавления | Статус | Статус получения данных | Черновик письма | Описание компании | Почта | Телефон | Предложение автоматизации | Рабор предлооженной автоматизации | Статус отправки письма
```

**Или импортируйте файл:** `google_sheets_template_companies.csv`

### Шаг 3: Создать лист "Запросы"

1. Создайте новый лист, назовите **"Запросы"**
2. Скопируйте эти заголовки в первую строку:

```
Запросы | Статус выполнения
```

**Или импортируйте файл:** `google_sheets_template_queries.csv`

### Шаг 4: Получить ID таблицы и листов

#### ID таблицы (Document ID):

Откройте таблицу, посмотрите URL:
```
https://docs.google.com/spreadsheets/d/[DOCUMENT_ID]/edit#gid=[SHEET_ID]
```

Скопируйте `DOCUMENT_ID` - это ID вашей таблицы.

**Текущий ID в workflows:** `1dqpNAXH8HmK_kExVa2wMeHAeF35x8-MIXN0xQbNUk8Y`

#### ID листов (Sheet gid):

**Лист "Компании":**
- Откройте лист "Компании"
- Посмотрите URL, найдите `gid=` в конце
- Скопируйте число после `gid=`
- Текущий gid в workflows: `0` (обычно первый лист имеет gid=0)

**Лист "Запросы":**
- Откройте лист "Запросы"
- Посмотрите URL, найдите `gid=`
- Скопируйте число
- Текущий gid в workflows: `1305865408`

### Шаг 5: Настроить доступ для n8n

1. В Google Sheets нажмите **"Настройки доступа"** (Share)
2. Дайте доступ сервисному аккаунту n8n
3. Или сделайте таблицу доступной по ссылке для редактирования

## Если у вас уже есть таблица

### Вариант A: Использовать существующую таблицу

1. Добавьте недостающие колонки
2. Убедитесь что названия совпадают ТОЧНО (включая регистр)
3. Скопируйте Document ID вашей таблицы
4. Обновите ID во всех workflow файлах

### Вариант B: Использовать новую таблицу (рекомендуется)

1. Создайте новую таблицу по инструкции выше
2. Скопируйте данные из старой таблицы
3. Document ID останется тот же, что в workflows: `1dqpNAXH8HmK_kExVa2wMeHAeF35x8-MIXN0xQbNUk8Y`

## Проверка настройки

### Тест 1: AI Agent добавляет запрос
1. Попросите AI Agent: "Найди строительные компании в Хабаровске"
2. Проверьте лист "Запросы" - должна появиться новая строка
3. В колонке "Статус выполнения" должно быть `0`

### Тест 2: Cycle 2 находит сайты
1. Подождите до 10 минут (или запустите Cycle 2 вручную в n8n)
2. Проверьте лист "Компании" - должны появиться найденные компании
3. Статус запроса в листе "Запросы" должен стать `1`

### Тест 3: AI Agent добавляет сайт вручную
1. Попросите AI Agent: "Добавь сайт https://example.com для компании TestCo"
2. Проверьте лист "Компании" - должна появиться новая строка
3. Колонки "Сайт" и "Компания" должны быть заполнены

## Решение проблем

### ❌ Ошибка: "Insufficient permissions"
**Решение:** Дайте n8n доступ к таблице (Share → Add email → Editor)

### ❌ Ошибка: "Document not found"
**Решение:** Проверьте Document ID в workflows

### ❌ Ошибка: "Sheet not found"
**Решение:** Проверьте названия листов (должны быть точно "Компании" и "Запросы")

### ❌ Данные не добавляются
**Решение:**
1. Проверьте названия колонок (должны совпадать точно)
2. Проверьте права доступа
3. Проверьте credentials в n8n

### ❌ Cycle 2 не находит сайты
**Решение:**
1. Добавьте API ключ Perplexity (см. FIXES_NEEDED.md)
2. Активируйте workflow Cycle 2 в n8n
3. Убедитесь что в "Запросы" есть строки со статусом `0`

## 🎯 Готовые файлы для импорта

В репозитории есть готовые CSV файлы:
- `google_sheets_template_companies.csv` - шаблон листа "Компании"
- `google_sheets_template_queries.csv` - шаблон листа "Запросы"

**Как импортировать:**
1. В Google Sheets: File → Import
2. Upload → выберите CSV файл
3. Import location: "Insert new sheet(s)"
4. Separator type: "Comma"
5. Переименуйте лист в "Компании" или "Запросы"
