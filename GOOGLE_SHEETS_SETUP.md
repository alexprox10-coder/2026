# 📊 Создание Google Sheets для системы сбора данных о компаниях

## 🎯 Быстрая настройка (5 минут)

### Шаг 1: Создайте новую Google таблицу

1. Откройте: https://sheets.google.com
2. Нажмите `+ Создать` → `Таблица`
3. Назовите её: **"Lead Company Database"** или **"База компаний"**

---

## 📋 Шаг 2: Создайте лист "CompanySites"

### Вариант 1: Импорт из CSV (быстро!)

1. **Скачайте файл:** `google_sheets_template_companies.csv`

2. **Импортируйте в Google Sheets:**
   - В Google Sheets: Файл → Импорт
   - Загрузите файл `google_sheets_template_companies.csv`
   - Выберите: "Заменить таблицу"
   - Разделитель: Запятая
   - Нажмите "Импортировать данные"

3. **Переименуйте лист:**
   - Внизу найдите вкладку листа
   - Правой кнопкой → Переименовать
   - Название: **`CompanySites`** (точно так!)

4. **Удалите строку с примером:**
   - Удалите строку 2 (пример данных)
   - Оставьте только заголовки

### Вариант 2: Создать вручную

1. **Переименуйте "Лист1":**
   - Внизу нажмите правой кнопкой на "Лист1"
   - Выберите "Переименовать"
   - Введите: **`CompanySites`**

2. **Добавьте заголовки в первую строку (A1:G1):**

| A | B | C | D | E | F | G |
|---|---|---|---|---|---|---|
| **ID** | **URL** | **Company Name** | **Status** | **Created At** | **Updated At** | **Source** |

3. **Форматирование заголовков:**
   - Выделите строку 1
   - Жирный шрифт (Ctrl+B)
   - Фон: серый или зеленый
   - Закрепите строку: Вид → Закрепить → 1 строку

4. **Настройка столбца ID (автонумерация):**
   - В ячейку A2 введите формулу: `=ROW()-1`
   - Растяните формулу вниз на 1000 строк (для запаса)

5. **Настройка ширины столбцов:**
   - A (ID): 50px
   - B (URL): 300px
   - C (Company Name): 200px
   - D (Status): 80px
   - E (Created At): 150px
   - F (Updated At): 150px
   - G (Source): 100px

---

## 📋 Шаг 3: Создайте лист "CompanyInformation"

### Вариант 1: Импорт из CSV (быстро!)

1. **Создайте новый лист:**
   - Нажмите `+` внизу таблицы

2. **Импортируйте данные:**
   - Файл → Импорт
   - Загрузите файл `google_sheets_template_company_info.csv`
   - Выберите: "Вставить новые листы"
   - Разделитель: Запятая
   - Импорт

3. **Переименуйте лист:**
   - Назовите: **`CompanyInformation`** (точно так!)

4. **Удалите строку с примером:**
   - Удалите строку 2
   - Оставьте только заголовки

### Вариант 2: Создать вручную

1. **Создайте новый лист:**
   - Нажмите `+` внизу таблицы
   - Переименуйте в **`CompanyInformation`**

2. **Добавьте заголовки (A1:L1):**

| A | B | C | D | E | F | G | H | I | J | K | L |
|---|---|---|---|---|---|---|---|---|---|---|---|
| **ID** | **Site ID** | **Company Name** | **INN** | **Address** | **Phone** | **Email** | **Description** | **Products/Services** | **Contact Person** | **Scraped At** | **Raw Data** |

3. **Форматирование:**
   - Выделите строку 1
   - Жирный шрифт
   - Фон: светло-зеленый
   - Закрепите строку

4. **Настройка столбца ID:**
   - В A2: `=ROW()-1`
   - Растяните вниз

5. **Настройка ширины:**
   - Все столбцы: 150-200px
   - Raw Data (L): 300px

## 🔑 Шаг 5: Получите ID таблицы

1. **Скопируйте URL из адресной строки:**
   ```
   https://docs.google.com/spreadsheets/d/1dqpNAXHBHmK_kEXVa2wMeHaE3Sx8-MfXI/edit
   ```

2. **ID таблицы** - это часть между `/d/` и `/edit`:
   ```
   1dqpNAXHBHmK_kEXVa2wMeHaE3Sx8-MfXI
   ```

3. **Сохраните этот ID** - он понадобится для настройки workflows!

## 📝 Шаг 6: Добавьте тестовые данные (опционально)

Для проверки работы системы добавьте несколько сайтов вручную:

### В лист CompanySites:

| ID | URL | Company Name | Status | Created At | Updated At | Source |
|----|-----|--------------|--------|------------|------------|--------|
| 1 | https://example1.ru | Тестовая компания 1 | 0 | 2026-01-14T10:00:00.000Z | 2026-01-14T10:00:00.000Z | manual |

## 🔐 Шаг 7: Настройте доступ для n8n

1. **Откройте настройки доступа:**
   - Нажмите "Настройки доступа" (правый верхний угол)

2. **Дайте доступ своему аккаунту:**
   - Убедитесь, что у вашего Google аккаунта есть доступ "Редактор"

3. **Для n8n OAuth2:**
   - В n8n при настройке Google Sheets credentials
   - Авторизуйтесь тем же аккаунтом Google
   - Разрешите доступ к таблице

---

## 🎯 Шаг 8: Используйте ID в workflows

Теперь замените `YOUR_GOOGLE_SHEET_ID_HERE` на ваш ID во всех узлах workflows:

1. Откройте workflow в n8n
2. Найдите все узлы Google Sheets
3. В каждом узле:
   - Document → By ID
   - Вставьте ваш ID таблицы
4. Сохраните

## 📊 Как это будет работать:

1. **Добавление сайта:**
   - Через API или вручную добавляется строка в `CompanySites`
   - Status = 0 (новый сайт, ждет обработки)

2. **Обработка workflow:**
   - Каждые 6 часов workflow ищет строки со Status = 0
   - Обновляет Status на 1 (в обработке)
   - Загружает HTML с сайта
   - AI извлекает данные
   - Сохраняет в `CompanyInformation`
   - Обновляет Status на 2 (успех) или 3 (ошибка)

3. **Результат:**
   - В `CompanySites`: список всех сайтов со статусами
   - В `CompanyInformation`: извлеченные данные о компаниях

## ❓ Частые проблемы:

### Проблема: "Sheet not found"
**Решение:** Проверьте, что название листа **точно** `CompanySites` (с большой буквы S)

### Проблема: "Column not found"
**Решение:** Проверьте, что все заголовки написаны правильно (с большой буквы, с пробелами)

### Проблема: "No rows with Status=0"
**Решение:**
- Добавьте тестовые данные вручную
- Убедитесь, что Status - это **цифра 0**, а не текст "0"
