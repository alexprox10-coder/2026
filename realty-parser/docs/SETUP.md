## 1️⃣ Создание Telegram бота

### Шаг 1: Создайте бота через @BotFather

1. Откройте Telegram и найдите **@BotFather**
2. Отправьте команду `/newbot`
3. Введите имя бота: `Парсер Недвижимости`
4. Введите username: `realty_parser_bot` (или любой другой доступный)
5. **Сохраните токен бота** (выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### Шаг 2: Настройте команды бота

Отправьте @BotFather команду `/setcommands` и выберите вашего бота, затем вставьте:

```
start - Главное меню
help - Помощь
settings - Настройки
```

### Шаг 3: Получите ваш Chat ID

1. Отправьте любое сообщение вашему боту
2. Откройте в браузере: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
3. Найдите `"chat":{"id":12345678}` - это ваш Chat ID
4. **Сохраните Chat ID**

## 2️⃣ Настройка Google Sheets

### Шаг 1: Создайте Google таблицу

1. Откройте [Google Sheets](https://sheets.google.com)
2. Создайте новую таблицу с названием **"Парсер Недвижимости"**
3. **Сохраните ID таблицы** из URL:
   `https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID/edit`

### Шаг 2: Создайте листы

Создайте 3 листа (вкладки) в таблице:

#### **Лист 1: "Объявления"**
Столбцы (первая строка):
```
Timestamp | Источник | URL | Цена | Цена_Текст | Адрес | Площадь | Комнаты | Этаж | Заголовок | Описание
```

#### **Лист 2: "Настройки"**
Столбцы и начальные значения:

| Параметр | Значение |
|----------|----------|
| enabled | true |
| interval_minutes | 15 |
| parsers | both |
| chat_id | ВАШ_CHAT_ID |
| price_min | 1000000 |
| price_max | 5000000 |
| location | Благовещенск |

**⚠️ ВАЖНО:** Замените `ВАШ_CHAT_ID` на ваш реальный Chat ID из Telegram!

#### **Лист 3: "История"**
Столбцы:
```
Timestamp | Парсер | Триггер | Статус
```

## 3️⃣ Импорт workflows в n8n

### Шаг 1: Откройте n8n

Перейдите на https://alex024.app.n8n.cloud

### Шаг 2: Импортируйте workflows

Для каждого из 5 файлов workflows:

1. Нажмите **"+" → "Import from File"**
2. Выберите файл:
   - `telegram-bot-control.json`
   - `avito-parser.json`
   - `cian-parser.json`
   - `unified-controller.json`
   - `auto-parser-scheduler.json`
3. Нажмите **"Import"**

### Шаг 3: Проверьте импорт

У вас должно быть 5 workflows:
- 🤖 Парсер Недвижимости - Telegram Bot
- 🏠 Avito Parser - Недвижимость
- 🏢 CIAN Parser - Недвижимость
- 🏘️ Unified Controller - ОБА парсера
- ⏰ Auto-Parser Scheduler

## 4️⃣ Настройка Credentials

### Telegram Bot API

Для **ВСЕХ 5 workflows** нужно настроить Telegram credentials:

1. Откройте любой workflow
2. Кликните на узел с Telegram (например, "📱 Telegram Trigger")
3. В поле **Credential for Telegram API** выберите **"Create New"**
4. Введите:
   - **Credential Name:** `Telegram Realty Bot`
   - **Access Token:** ваш токен от @BotFather (из шага 1)
5. Нажмите **"Save"**
6. Для остальных узлов Telegram выбирайте созданный credential

**⚠️ Важно:** Примените этот credential ко ВСЕМ Telegram узлам во ВСЕХ workflows!

### Google Sheets OAuth2

Для workflows с Google Sheets узлами:

1. Откройте workflow с узлом Google Sheets
2. Кликните на узел **"💾 Save to Sheets"** или **"💾 Read Settings"**
3. В поле **Credential** выберите **"Create New"**
4. Выберите **"OAuth2"**
5. Нажмите **"Connect my account"**
6. Авторизуйтесь через Google
7. Дайте разрешения n8n
8. Нажмите **"Save"**

**Обновите Document ID:**
В каждом Google Sheets узле замените `YOUR_GOOGLE_SHEET_ID` на ваш реальный ID таблицы!

### Anthropic Claude API (Опционально)

Если хотите использовать AI анализ:

1. Получите API Key на https://console.anthropic.com
2. В n8n создайте Anthropic credential
3. Добавьте AI узлы в workflows (по аналогии с новостным workflow)

## 5️⃣ Активация workflows

### Шаг 1: Активируйте Telegram Bot

1. Откройте workflow **"🤖 Парсер Недвижимости - Telegram Bot"**
2. Нажмите переключатель **"Active"** в правом верхнем углу
3. **Важно:** Убедитесь, что Telegram Trigger настроен на **"Webhook"** mode

### Шаг 2: Активируйте парсеры

Активируйте следующие workflows:
- ✅ 🏠 Avito Parser
- ✅ 🏢 CIAN Parser
- ✅ 🏘️ Unified Controller

**Примечание:** Эти workflows запускаются через webhook, поэтому их не нужно держать активными постоянно. Но для надежности лучше активировать.

### Шаг 3: Активируйте Auto-Scheduler

1. Откройте **"⏰ Auto-Parser Scheduler"**
2. Убедитесь, что в Google Sheets в листе "Настройки" параметр `enabled = true`
3. Проверьте, что `chat_id` правильно указан
4. Активируйте workflow

## 6️⃣ Тестирование

### Тест 1: Главное меню

1. Откройте Telegram
2. Найдите вашего бота
3. Отправьте `/start`
4. Должна появиться клавиатура с кнопками:
   - 🏠 Парсить Авито
   - 🏢 Парсить ЦИАН
   - 🏘️ Парсить ОБА
   - и т.д.

### Тест 2: Запуск парсинга

1. Нажмите кнопку **"🏠 Парсить Авито"**
2. Должно прийти сообщение: "Запуск парсинга Avito..."
3. Через 30-60 секунд должны начать приходить объявления
4. Проверьте Google Sheets - там должны появиться записи

### Тест 3: Автопарсинг

1. Дождитесь следующего срабатывания auto-scheduler (по умолчанию каждые 15 минут)
2. Или временно измените интервал на 1 минуту в workflow
3. Проверьте, что парсинг запускается автоматически
4. Проверьте лист "История" в Google Sheets

## 7️⃣ Настройка параметров поиска

### Изменение фильтров для Avito

Откройте workflow **"🏠 Avito Parser"**, найдите узел **"📥 Fetch Avito"**.

В URL можно изменить параметры:
```
https://www.avito.ru/blagoveshchensk/kvartiry/prodam
  ?pmax=5000000        # Максимальная цена
  &pmin=1000000        # Минимальная цена
  &f=1.2               # Количество комнат (1 и 2)
  &s=104               # Сортировка по дате
```

**Параметры Avito:**
- `pmin` - минимальная цена (в рублях)
- `pmax` - максимальная цена (в рублях)
- `f=1` - 1-комнатные
- `f=2` - 2-комнатные
- `f=1.2.3` - 1, 2 и 3-комнатные
- `s=104` - сортировка по дате (новые первые)

### Изменение фильтров для CIAN

Откройте workflow **"🏢 CIAN Parser"**, найдите узел **"📥 Fetch CIAN API"**.

В bodyParameters → jsonQuery измените:
```json
{
  "region": {"type": "location", "value": [4593]},  // 4593 = Благовещенск
  "room": {"type": "terms", "value": [1,2]},        // Комнаты: 1 и 2
  "price": {
    "type": "range",
    "value": {"gte": 1000000, "lte": 5000000}       // Цена от-до
  }
}
```

## 8️⃣ Решение проблем

### Проблема: Не приходят объявления

**Решение:**
1. Проверьте n8n executions (вкладка Executions)
2. Посмотрите на ошибки в красных узлах
3. Возможные причины:
   - Avito/CIAN изменили структуру сайта
   - Заблокирован доступ (нужен VPN)
   - Неверные credentials

### Проблема: "No items found"

**Решение:**
1. Возможно, нет объявлений по заданным критериям
2. Измените фильтры (цена, комнаты)
3. Проверьте URL в браузере - открывается ли страница Avito/CIAN

### Проблема: Telegram не отвечает

**Решение:**
1. Проверьте, что Telegram Bot workflow активен
2. Проверьте, что токен правильный (отправьте `/start` боту)
3. В n8n проверьте webhook URL: Settings → n8n → Webhook URL

### Проблема: Автопарсинг не работает

**Решение:**
1. Проверьте Google Sheets лист "Настройки":
   - `enabled` должен быть `true`
   - `chat_id` должен быть правильным
2. Проверьте, что Auto-Scheduler workflow активен
3. Проверьте историю в executions

### Проблема: Слишком много объявлений

**Решение:**
1. Ужесточите фильтры (цена, комнаты)
2. В Code узле парсеров измените `.slice(0, 20)` на меньшее число

## 📊 Мониторинг и статистика

### Просмотр выполнений

1. В n8n откройте вкладку **"Executions"**
2. Здесь видны все запуски workflows
3. Зеленые = успешные, Красные = ошибки
4. Кликните на execution чтобы увидеть детали

### Google Sheets как база данных

- **Лист "Объявления"** - все найденные объявления
- **Лист "История"** - логи автопарсинга
- **Лист "Настройки"** - конфигурация

Можно создать сводные таблицы и графики для анализа рынка!
