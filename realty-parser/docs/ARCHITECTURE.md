# Архитектура Парсера-Монитора Недвижимости

## 📋 Обзор системы

Система состоит из 5 основных n8n workflows, работающих вместе для мониторинга недвижимости на Авито и ЦИАН с управлением через Telegram бот.

## 🏗️ Компоненты системы

### 1. **Telegram Bot Control Panel** (`telegram-bot-control.json`)
**Назначение:** Главный интерфейс управления всей системой

**Функции:**
- ✅ Прием команд от пользователя через Telegram
- ✅ Inline клавиатура с кнопками управления
- ✅ Роутинг команд к соответствующим workflows
- ✅ Управление настройками автопарсинга
- ✅ Помощь и связь с владельцем

**Кнопки управления:**
```
┌─────────────────────────────────┐
│  🏠 Парсить Авито              │
│  🏢 Парсить ЦИАН               │
│  🏘️ Парсить ОБА                │
├─────────────────────────────────┤
│  ⏸️ Остановить  │  ▶️ Запустить │
├─────────────────────────────────┤
│  ⏰ Автопарсинг (настройка)     │
│  ❓ Помощь / Связаться          │
└─────────────────────────────────┘
```

**Триггеры:**
- Webhook от Telegram Bot API
- Команды: `/start`, `/help`, `/settings`

---

### 2. **Avito Parser** (`avito-parser.json`)
**Назначение:** Парсинг объявлений о недвижимости с Avito

**Логика работы:**
1. **Триггер:** Webhook (от Telegram бота) или Schedule
2. **Парсинг:** HTTP Request к Avito с параметрами поиска
3. **Извлечение данных:**
   - Заголовок объявления
   - Цена
   - Адрес / Район
   - Площадь / Комнаты
   - Фото (URL)
   - Ссылка на объявление
   - Дата публикации
4. **Фильтрация:**
   - Цена (мин/макс)
   - Район
   - Площадь
   - Тип жилья
   - Дата (только свежие, не старше X часов)
5. **AI Анализ (опционально):**
   - Claude Sonnet анализирует описания
   - Выбирает топ-10 лучших предложений
   - Находит подозрительные объявления
6. **Отправка:**
   - Telegram (в канал или группу)
   - Google Sheets (архив)
7. **Дедупликация:** Проверка на дубли по URL

**Параметры поиска:**
```json
{
  "location": "Благовещенск",
  "category": "kvartiry",
  "priceTo": 5000000,
  "priceFrom": 1000000,
  "rooms": [1, 2],
  "sort": "date_desc"
}
```

---

### 3. **CIAN Parser** (`cian-parser.json`)
**Назначение:** Парсинг объявлений о недвижимости с ЦИАН

**Логика работы:**
Аналогична Avito Parser, но адаптирована под API/структуру ЦИАН:

1. **Триггер:** Webhook или Schedule
2. **Парсинг:** HTTP Request к CIAN API
3. **Извлечение данных:**
   - ID объявления
   - Заголовок
   - Цена (₽)
   - Адрес (координаты)
   - Характеристики (площадь, этаж, комнаты)
   - Фото
   - Дата размещения
4. **Фильтрация:** По тем же критериям
5. **AI Анализ:** Claude для ранжирования
6. **Отправка:** Telegram + Google Sheets
7. **Дедупликация:** По ID объявления

**CIAN API Endpoint:**
```
https://api.cian.ru/search-offers/v2/search-offers-desktop/
```

---

### 4. **Unified Controller** (`unified-controller.json`)
**Назначение:** Запуск обоих парсеров одновременно и объединение результатов

**Логика работы:**
1. **Триггер:** Webhook от Telegram бота (кнопка "Парсить ОБА")
2. **Параллельный запуск:**
   - Execute Workflow: Avito Parser
   - Execute Workflow: CIAN Parser
3. **Ожидание:** Wait for completion обоих workflows
4. **Объединение результатов:**
   - Merge данных от обоих парсеров
   - Сортировка по дате/цене/релевантности
5. **Дедупликация:**
   - Удаление дублей (по адресу + цене)
6. **AI Сравнительный анализ:**
   - Claude сравнивает предложения
   - Находит лучшие варианты
   - Выявляет расхождения в ценах
7. **Отправка сводного отчета:**
   - Telegram: Топ-20 предложений
   - Google Sheets: Полный архив
   - Статистика: Кол-во объявлений, средняя цена, тренды

---

### 5. **Auto-parser Scheduler** (`auto-parser-scheduler.json`)
**Назначение:** Автоматический запуск парсинга по расписанию

**Логика работы:**
1. **Триггер:** Schedule (Cron)
   - Настраиваемый интервал (от 1 минуты)
   - Хранится в переменных окружения или Google Sheets
2. **Проверка настроек:**
   - Чтение конфига автопарсинга из Google Sheets
   - Параметры:
     - `enabled`: true/false
     - `interval_minutes`: 1-1440 (1 мин - 24 часа)
     - `parsers`: ["avito", "cian", "both"]
     - `filters`: объект с фильтрами
3. **Условный запуск:**
   - IF enabled === true
   - Switch по значению `parsers`
   - Запуск соответствующего парсера
4. **Логирование:**
   - Запись в Google Sheets:
     - Timestamp
     - Какой парсер запущен
     - Кол-во найденных объявлений
     - Статус (success/error)

**Cron настройки:**
```
Каждую минуту:    */1 * * * *
Каждые 5 минут:   */5 * * * *
Каждые 15 минут:  */15 * * * *
Каждый час:       0 * * * *
```

## ⚠️ Важные замечания:

### Легальность парсинга:
- ⚠️ Avito и CIAN могут блокировать scraping
- ✅ Используйте официальные API где возможно
- ✅ Добавьте rate limiting (паузы между запросами)
- ✅ Используйте User-Agent браузера
- ✅ Respect robots.txt

### Rate Limits:
- Telegram: макс 30 сообщений/сек
- Avito: ~1 запрос в 3-5 секунд (рекомендуется)
- CIAN: API limits (если есть API key)
- Claude API: зависит от тарифа

### Затраты:
- Claude Sonnet: ~$0.01-0.03 за анализ 20 объявлений
- n8n Cloud: зависит от тарифа и кол-ва executions
- Рекомендация: запускать не чаще 1 раза в 15 минут
