# 🏠 Парсер-Монитор Недвижимости для Авито и ЦИАН

Полноценная система мониторинга объявлений о недвижимости на Авито и ЦИАН с управлением через Telegram бота и автоматическим парсингом.

## 🎯 Возможности

- ✅ **Telegram бот с удобными кнопками управления**
- ✅ **Парсинг Авито** - автоматический поиск квартир
- ✅ **Парсинг ЦИАН** - API интеграция
- ✅ **Объединенный парсинг** - поиск на обоих сайтах одновременно
- ✅ **Автопарсинг** - автоматический запуск по расписанию (от 1 минуты)
- ✅ **Фильтрация** - по цене, комнатам, району, свежести
- ✅ **Google Sheets** - сохранение всех результатов
- ✅ **AI анализ** (опционально) - Claude Sonnet для ранжирования

## 🏗️ Архитектура

Система состоит из 5 n8n workflows:

1. **Telegram Bot Control Panel** - главный интерфейс управления
2. **Avito Parser** - парсинг Авито
3. **CIAN Parser** - парсинг ЦИАН через API
4. **Unified Controller** - запуск обоих парсеров
5. **Auto-Parser Scheduler** - автоматический запуск по расписанию

## 📋 Требования

- n8n Cloud аккаунт (или self-hosted)
- Telegram Bot Token (от @BotFather)
- Google Account (для Google Sheets)
- Anthropic API Key (опционально, для AI анализа)

## 🚀 Быстрый старт

### 1. Создайте Telegram бота
```bash
1. Откройте @BotFather в Telegram
2. Отправьте /newbot
3. Сохраните полученный токен
```

### 2. Создайте Google Sheets таблицу
- Создайте таблицу с 3 листами: "Объявления", "Настройки", "История"
- Сохраните ID таблицы

### 3. Импортируйте workflows в n8n
```bash
1. Откройте n8n
2. Import from File для каждого файла из папки workflows/
3. Настройте credentials (Telegram, Google Sheets)
4. Замените YOUR_GOOGLE_SHEET_ID на реальный ID
5. Активируйте все workflows
```

### 4. Запустите бота
```bash
1. Откройте Telegram
2. Найдите вашего бота
3. Отправьте /start
4. Нажмите "🏠 Парсить Авито"
```

## ⚙️ Настройка параметров поиска

### Avito
В workflow "Avito Parser" → узел "Fetch Avito" → URL:
```
?pmax=5000000    # Макс цена
&pmin=1000000    # Мин цена
&f=1.2           # Комнаты (1 и 2)
```

### CIAN
В workflow "CIAN Parser" → узел "Fetch CIAN API" → bodyParameters:
```json
{
  "price": {"type": "range", "value": {"gte": 1000000, "lte": 5000000}},
  "room": {"type": "terms", "value": [1,2]}
}
```

### Автопарсинг
В Google Sheets → лист "Настройки":
- `interval_minutes` - интервал в минутах (1-1440)
- `parsers` - какой парсер запускать (avito/cian/both)
- `enabled` - включен ли автопарсинг (true/false)

## ⚠️ Важные замечания

1. **Легальность парсинга:**
   - Avito и CIAN могут блокировать web scraping
   - Используйте официальные API где возможно
   - Добавьте паузы между запросами (rate limiting)

2. **Rate Limits:**
   - Telegram: макс 30 сообщений/сек
   - Avito: рекомендуется 1 запрос в 3-5 секунд
   - Не запускайте автопарсинг чаще 1 раза в 5-15 минут

3. **Затраты:**
   - n8n Cloud: зависит от количества executions
   - Claude API (если используется): ~$0.01-0.03 за анализ

## 🛠️ Решение проблем

**Не приходят объявления:**
- Проверьте Executions в n8n на ошибки
- Avito/CIAN могли изменить структуру сайта
- Попробуйте открыть URL в браузере

**Telegram не отвечает:**
- Проверьте токен бота
- Убедитесь, что workflow активен
- Проверьте webhook URL в n8n Settings

**Автопарсинг не работает:**
- Проверьте `enabled = true` в Google Sheets
- Проверьте правильность `chat_id`
- Убедитесь, что Auto-Scheduler активен
