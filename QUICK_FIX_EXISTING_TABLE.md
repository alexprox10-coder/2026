# Быстрая адаптация существующей таблицы

## Проблема:
У вас есть таблица "Таблица1" с 30 сайтами, но структура не совпадает с тем, что ожидает workflow.

## Решение (5 минут):

### Шаг 1: Переименуйте лист
1. Правой кнопкой на "Таблица1" → Переименовать
2. Новое имя: **CompanySites** (точно так!)

### Шаг 2: Переименуйте колонки

**Было:**
```
company_name | website | city | phone | email | description | source_query | found_date | status
```

**Должно быть (минимум):**
```
ID | URL | Company Name | Status | Created At | Updated At | Source
```

**Как изменить:**
1. Вставьте новую колонку A (для ID)
2. Переименуйте колонки:
   - B: `website` → `URL`
   - C: `company_name` → `Company Name`
   - Удалите: city, phone, email, description, source_query
   - D: `status` → `Status`
   - E: `found_date` → `Created At`
   - F: добавьте `Updated At`
   - G: добавьте `Source`

### Шаг 3: Исправьте данные

#### Колонка A (ID):
В A2 введите формулу:
```
=ROW()-1
```
Растяните вниз на все строки.

#### Колонка D (Status):
**ВАЖНО!** Замените все значения `new` на число **0**:
1. Выделите колонку D
2. Ctrl+H (Найти и заменить)
3. Найти: `new`
4. Заменить на: `0`
5. Заменить все

#### Колонка F (Updated At):
Скопируйте значения из E (Created At)

#### Колонка G (Source):
Поставьте везде: `manual`

### Шаг 4: Создайте второй лист

1. Нажмите `+` внизу
2. Импортируйте CSV: `google_sheets_template_company_info.csv`
3. Переименуйте в: **CompanyInformation**
4. Удалите пример (строка 2)

### Шаг 5: Проверьте

Лист CompanySites должен выглядеть так:

| ID | URL | Company Name | Status | Created At | Updated At | Source |
|----|-----|--------------|--------|------------|------------|--------|
| 1 | https://khabarovsk.jilfond.ru | Жилфонд | **0** | 2026-01-14... | 2026-01-14... | manual |

**Критично:** Status = **0** (число), не текст!

### Шаг 6: Настройте workflow

1. Скопируйте ID таблицы из URL
2. В workflow замените `YOUR_GOOGLE_SHEET_ID_HERE` на ваш ID
3. Сохраните

### Шаг 7: Запустите обработку

1. Откройте workflow: `child_workflow_03_AgentLeadScrapInformationCompany_FIXED`
2. Нажмите "Execute Workflow"
3. Workflow найдет 30 сайтов со статусом 0
4. Начнет обработку

---

## ⚠️ Важно понять:

**Система НЕ ищет сайты автоматически!**

Работа системы:
1. **ВЫ добавляете** сайты (вручную или через API) → Status = 0
2. **Workflow обрабатывает** эти сайты → Status = 1 (в процессе) → 2 (готово) или 3 (ошибка)

Нет никакого "автоматического поиска в интернете"!
